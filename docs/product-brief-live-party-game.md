# 실시간 소셜 놀이 제품 기획서 (2026-10-13, 첫 검증)

> **핵심 장면:** 한 사람이 놀이를 열고 링크를 보내면 사람들이 같은 방에 모여 동시에 플레이한다. 끝난 뒤 참여자와 결과를 함께 보고 공유한다. [사업 방향과 실행 계획](business-plan-2026.md).

## 공통 경험

- **준비:** 게임마다 필요한 속성만 채우고 바로 미리본다. 퀴즈라면 문제를, 캐릭터 게임이라면 참가자 닉네임 같은 속성을 바꾼다. AI 생성은 필수가 아니다.
- **초대:** 방장은 링크만으로 입장할지, 추가 비밀번호(PIN)를 요구할지 선택한다. PIN은 초대 링크에 넣지 않는다. 참가자는 설치·로그인 없이 입장하되, 잠긴 방에서는 PIN 확인 후 인원과 닉네임을 본다.
- **동시 플레이:** 시작·남은 시간·상태 변화가 모든 화면에서 일치한다. 참가자의 조작 또는 응답이 실제 결과에 반영된다.
- **결과:** 참여자와 점수·순위 또는 공동 결과물을 보여주고 재경기·공유를 제공한다. 경쟁이 아닌 놀이에 억지로 순위를 붙이지 않는다. 첫 버전은 계정이나 상시 보관 대신 저장·전송 가능한 결과 이미지면 충분하다.

## 첫 대표 게임

첫 대표 게임은 **나 맞히기**다. 모임 섭외 없이 무료 베타를 열고 실제 이용에 따라 고친다.

선택한 게임에만 다음을 완성한다.

1. AI 키 없이 쓰는 게임별 속성 편집과 미리보기. 편집 내용이 실제 공유 링크와 플레이에 그대로 반영된다.
2. 친구 초대 링크, 선택적 방 PIN, 대기방의 인원·닉네임, 시작 제어, 늦은 입장·재접속 안내.
3. 모두가 함께 보는 진행·결과, 결과 이미지, 같은 그룹의 재경기·새 판 시작.

`여기 중에 누군지 맞히기`, `우리 중 누가?`, 모임 캐릭터 퀴즈는 나 맞히기에서 파생되는 후속 후보로 둔다. 여러 게임 중 실기기에서 검증했거나 수정 완료된 것은 추천작으로 올리고, 수정 중인 것은 추천 후보/실험작으로 둔다. 여러 테마나 공동 창작 도구를 첫 출시의 로드맵으로 확정하지 않는다.

## 후속 재미 요소

- **셀카 캐릭터:** 참가자가 직접 선택한 경우에만 셀카를 찍거나 사진을 골라 개인 캐릭터를 만든다. 촬영이 끝나면 카메라를 닫고, 미리본 뒤 사용할지 선택한다. 사진 없이도 기본 캐릭터로 바로 입장하며 첫 무료 베타의 출시 조건은 아니다.
- 사진 원본은 기본 저장하지 않는다. 다른 참가자에게 보이는 결과물과 보관·삭제 범위는 구현 전에 명확히 안내한다. 카메라 권한 거부나 미지원 환경에서도 입장이 막히지 않아야 한다.

## 사용자 반응 확인

- 플레이 중에는 묻지 않는다. 결과 화면에서 재경기·공유를 가리지 않는 선택형 한 문항('다음에도 하고 싶나요?')만 보여주고, 건너뛸 수 있게 한다. 부정 응답에는 이유를 고르는 선택지를 둘 수 있다.
- 방 생성·입장·완료·재경기·공유·오류와 함께 질문 노출·응답 건수를 게임별로 집계한다. 응답하지 않은 사람도 있으므로 긍정 응답률만으로 재미를 판정하지 않는다.
- 반응 측정에는 카메라·마이크·사진을 사용하지 않는다. 플레이 중 촬영하거나 녹화하지 않는다. 현재 [익명 측정](telemetry.md)에는 반응 이벤트가 없으므로 공개 전 스키마와 화면 연결이 필요하다.

## 실시간 품질 게이트

- 자동 다중 클라이언트 시험으로 20판 이상 반복하고, 실기기에서는 iOS·Android 카카오톡 브라우저 입장을 반복 확인한다. 실제 기기 3대 이상으로 한 판을 끝내며 시작·결과 일치와 재접속을 확인한다. 이는 모임 섭외가 아닌 공개 전 품질 점검이다.
- 자동 게이트와 실기기 화면 확인을 함께 통과한다. 실패한 경로는 회귀 테스트로 남긴다.
- 공개 MQTT 방은 소규모 테스트까지만 사용하고, 실명·사진을 넣지 않는다. 현재 구조에 PIN 입력 화면만 붙여서는 방 메시지를 보호할 수 없다. 불특정 다수에게 무료 베타를 공개하기 전에는 [인증된 방과 기존 품질 게이트](master-plan.md)를 통과한다. 서버가 링크 권한과 선택적 PIN을 검증한 뒤 해당 방에만 접속 가능한 단기 권한을 발급하고, PIN 추측 시도를 제한한다. 참가자 로그인은 필수가 아니다.

다음 테마와 제작 방식은 무료 베타의 실제 사용을 보고 정한다.
