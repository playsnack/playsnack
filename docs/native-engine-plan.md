# 네이티브 엔진 계획 — Bite 코어를 Rust로 (웹 · 서버 · iOS · 안드로이드 공용)

> ⚠️ **보류 (2026-10-12):** 크리틱 3라운드 결과, 이 계획은 보류하고 `docs/master-plan.md`의 조건부 엔진 단계(E0~E5, G1 측정 게이트)로 흡수했다.
> 근거는 `docs/audit/2026-10-12-plan-critique.md`. 핵심은 세 가지다.
> - "네이티브엔 JS가 없다"는 전제가 틀렸다.
> - 순서가 거꾸로다.
> - 이모지 · 식 의미론 · 인앱 브라우저 GPU를 고려하지 않았다.
>
> 아래는 기록용 초안이다.

## 0. 왜 / 목적지
- **비전:** 지금은 탭 위주의 간단한 2D 스낵 앱이다. 앞으로 3D 게임까지 가고, 최종적으로는 사용자가 게임을 만들어 같이 플레이하는 **생태계**(마인크래프트 · 로블록스 같은 UGC)를 만든다.
- **문제:** 지금 엔진(TS 런타임 + Yoga + Pixi)은 웹 · 웹뷰에서는 충분하다. 하지만 아래 셋에서는 한계가 있다.
  - 블러 · 글라스를 겹겹이 쓰는 고급 효과
  - 웹뷰 없는 네이티브 앱
  - 3D
- **목적지:** Bite 코어(런타임 + 레이아웃 + 렌더러)를 Rust 하나로 만들어 웹(WASM) · 서버 검증(WASM) · iOS(Metal) · 안드로이드(Vulkan)에서 같은 코드로 쓴다.

## 1. 원칙
1. 포맷은 우리 것, 기반은 오픈소스, 그 사이는 어댑터(소켓).
2. 오픈소스는 MIT / Apache-2.0 / BSD(폰트는 OFL)만 쓴다. 활발히 관리되는 것만 고르고 버전을 고정한다.
3. 직접 쥐는 건 포맷 · 식 샌드박스 · 화면 없는 검증 · 멀티 연결 · AI 생성뿐이다.
4. 웹 링크가 1순위다. 첫 로딩과 품질을 해치지 않는다.
5. 라이브 서비스는 깨지 않는다. 채점표와 게이트를 통과해야만 교체한다.
6. 믿지 말고 측정한다. 큰 선택은 실기기 스파이크로 정한다.

## 6. 경계 — 모션 · 인터랙션 상태는 엔진 밖 (2026-10-14 결정)

**왜.** Bite는 모션 라이브러리(nudg, 같은 소유자의 별도 프로젝트)보다 먼저 만들어져 모션 자리가 비어 있었다(감사 "손맛 0": 포맷에 트윈 프리미티브가 없다). 그 자리를 포맷 안에 만들지 않고, **엔진 밖의 조립**으로 채운다. 두 프로젝트는 각자 발전하고, 같이 쓸 때의 시너지는 앱에서 난다.

**분담.**
| 층 | 맡는 것 | 어디 |
|---|---|---|
| 렌더링 | 그리기 · 히트테스트 · 폰트 · 스크롤 | Bite (`bite-pixi`, 장기 Rust 렌더러) |
| UI | 문서 구조 · 레이아웃 · 노드 · vars · 앱 단계(`phases`) | Bite (`bite`, `bite-layout`) |
| 모션 · 인터랙션 상태 | 컴포넌트 안의 상태(눌림 · 열림 · 드래그) · 이벤트 규칙 · 스프링 · 타이머 | 모션 라이브러리 (현재 nudg) |
| 조립 | 둘을 import해 잇기 | 앱 (`snack-player`) |

"상태"가 겹치는 곳의 선: **앱 단계는 Bite의 `phases`, 컴포넌트 인터랙션은 모션 라이브러리.**

**규칙.**
1. `packages/bite*`는 모션 라이브러리를 import하지 않고 이름도 모른다. 모션 라이브러리도 Bite를 모른다. 의존성 양방향 0.
2. 포맷에 트윈 · 스프링 · 제스처 상태를 넣지 않는다. 노드 속성은 **목표값**이다(§3 v1.x 노드 포함).
3. Bite가 여는 것은 **범용 확장점**뿐이다(모션 라이브러리를 몰라도 쓸 수 있는 모양):
   - 노드 속성의 목표값이 바뀔 때 앱이 끼어드는 훅 — `onNodeChange(node, prop, from, to)` 꼴
   - 앱이 프레임마다 그릴 값을 써 넣는 세터 — `setNodeValue(node, prop, value)` 꼴
   - 포인터 이벤트(down · move · up · cancel)를 앱이 받는 통로
4. 렌더러의 하드코딩 눌림(`PRESS_SCALE`, `renderer.js`)은 3이 생기면 앱 쪽 모션으로 옮기고 지운다.
5. 조립은 `snack-player`에서 한다. 의사 코드: 훅에서 `animatedValue(motion).retarget(to, now)`를 만들고, ticker마다 `at(now)`를 세터로 돌려준다. 결정성은 Bite의 `now` 주입을 그대로 넘기면 유지된다.

**지금 상태(2026-10-14).** React 껍데기의 블록 눌림 · 초대 토스트는 nudg로 되어 있다(PR #16). 그 이상 확장은 멈추고, Bite 앱 안에 모션이 필요해지는 시점에 위 확장점으로 조립을 한 번 시험해 결정한다. 안 되면 React 껍데기는 다른 라이브러리로 바꾼다.
