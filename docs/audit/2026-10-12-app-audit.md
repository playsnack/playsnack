# Live app audit — 2026-10-12 (playsnack.vercel.app, serverless build)

Method: real touch taps on all 44 templates (mobile 390×844), 2–3-player rooms (lobby → countdown → play → result, late join, leave, host leave, reload, solo, odd nicknames), shell screens, bad links, slow-3G, small/landscape viewports. Multiplayer findings other than MP-01 were reproduced with the browser rerouted to broker.hivemq.com (emqx refused all connections). Evidence screenshots lived in the session scratchpad (not kept).

**60 itemized findings — P0 3 · P1 20 · P2 28 · P3 9.**
The audit agent reported 65 (P2 31 · P3 11), but only these 60 rows were itemized, so treat 60 as the count.
Severity: P0 broken/blocks use · P1 clearly wrong/ugly · P2 awkward/polish · P3 nit.

## Systemic patterns (fix the root, not each symptom)
1. **Single hard-coded public broker, no fallback, no error UI, no private rooms** (MP-01…04).
2. **Room state sync leaks** (MP-05…08):
   - Join and reload send only `sharedState()`, so round vars are missing.
   - The periodic resync overwrites per-player sends.
   - Hand-over snapshots diverge.
   - Timed scores use the host clock.
3. **Validator misses semantic errors:** an emit payload without `{}` and an out-of-range `origin` both ship (T-01, T-02).
4. **Static, unshareable results:** same copy regardless of score, no share/next/home, inconsistent CTAs (T-05, T-09…15, T-20).
5. **Retry doesn't reshuffle,** and some content is fully fixed (T-03, T-07, T-16, T-17).
6. **Copy drift:** in-app titles ≠ home cards (6 worldcups all "최애 월드컵"), name collisions, English labels, "서버" mentions.
7. **Shell outside the design system:** Create, error and loading screens ignore tokens (serif fallback, rounded components, monospace errors, pixel font misuse).
8. **Top-heavy layouts:** empty lower halves, generic lime circle/🏆 filler, 💬 dock colliding with bottom CTAs.
