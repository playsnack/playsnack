# Feature Specification: 실데이터 월드컵 (Live-Data Worldcups)

**Feature Branch**: `002-live-data-worldcups`

**Created**: 2026-06-29

**Status**: Draft

**Input**: 인물/음원 월드컵 콘텐츠 신선도를 실데이터로 끌어올린다 — Melon 차트 = 음원 월드컵(신규), 인물 월드컵 = brikorea 아이돌 개인 브랜드평판. 둘 다 시드파일 방식(서버가 외부 소스를 런타임 직접 호출 불가), 하루(음원)·월(인물) 갱신, 실패 시 graceful 폴백, 캐시·프리워밍으로 레이턴시 감소.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 음원 월드컵 (Priority: P1)

플레이어가 "오늘의 음원 월드컵"에 들어가면, **지금 차트에서 뜨는 실제 곡들**(곡명·아티스트)이 16강 토너먼트로 나오고 둘 중 더 좋아하는 곡을 골라 우승곡을 가린다. 풀은 매일 아침 한 번 새 차트로 갈린다.

**Why this priority**: 가장 깨끗한 실데이터 적용 — 차트가 곡·아티스트를 바로 주므로 매핑 가공이 최소. 새 카테고리(음원)를 더해 카탈로그도 넓힌다.

**Independent Test**: 음원 월드컵 앱 하나만으로 검증 가능 — 들어가서 16강이 *현재 차트의 실제 곡*으로 채워지고, 탭으로 끝까지 진행해 우승곡이 나오면 가치 전달.

**Acceptance Scenarios**:

1. **Given** 오늘 시드가 적용된 상태, **When** 음원 월드컵 진입, **Then** 16강 후보가 현재 차트 기반 실제 곡들로 채워지고 토너먼트가 끝까지 정상 진행된다.
2. **Given** 어제와 다른 차트, **When** 다음날 09시 이후 진입, **Then** 풀이 새 차트로 갱신돼 있다(전날과 다른 곡 등장).
3. **Given** 같은 날 두 번 진입, **When** 재진입, **Then** 풀이 그날 안엔 안정적이다(매번 재생성되지 않음).

---

### User Story 2 - 인물 월드컵 신선도 (Priority: P2)

가수/아이돌 인물 월드컵(idol-m/f, singer-m/f)의 후보가 **현재 브랜드평판 순위의 실제 인물**로 채워지고, 최근 급상승/신인이 최소 1명 섞여 "맨날 같은 톱티어"에서 벗어난다. 성별 구분이 정확하다.

**Why this priority**: 기존 인물 월드컵의 핵심 약점(LLM 기억상 고정 톱티어 수렴) 해결. 음원보다 가공(성별 분류·그룹 멤버 펼침·이미지 매핑)이 더 필요해 P2.

**Independent Test**: idol-f 월드컵 진입 → 후보 16명이 현재 평판 순위 기반 + 신인 최소 1명 + 전원 여성 + 사진이 본인으로 정확히 표시.

**Acceptance Scenarios**:

1. **Given** 이번 달 인물 시드 적용, **When** idol-f 진입, **Then** 후보가 현재 순위 기반이고 신인/급상승이 ≥1명 포함된다.
2. **Given** idol-m 진입, **When** 후보 확인, **Then** 전원 남성으로 정확히 분류돼 있다(성별 혼입 없음).
3. **Given** 후보에 신상 인물 포함, **When** 카드 렌더, **Then** 그 인물의 정확한 사진이 뜨고(틀린 얼굴 금지), 없으면 이름 플레이스홀더(빈/엉뚱한 사진 금지).

---

### User Story 3 - 빠른 로딩 (Priority: P2)

월드컵 진입 시 풀과 사진이 **즉시** 떠서 LLM 생성을 기다리는 대기/딤이 길지 않다.

**Why this priority**: 사용자가 명시한 목표(레이턴시 감소). 시드+일/월 캐시로 진입 시 LLM 생성이 없고, 사진은 미리 데워져 있어야 함.

**Independent Test**: 풀이 그날 캐시된 상태에서 진입 → 첫 대결 카드가 수 초 내 사진까지 뜬다(긴 회색/딤 없음).

**Acceptance Scenarios**:

1. **Given** 오늘 풀이 이미 캐시됨, **When** 월드컵 진입, **Then** 후보 텍스트는 즉시, 첫 대결 사진은 짧은 시간 내 뜬다(콜드 LLM 대기 없음).

### Edge Cases

- 시드 파일이 없거나 손상 → 기존 LLM-only 생성으로 graceful 폴백(앱 안 깨짐).
- 외부 소스가 비었거나 갱신 실패 → 직전 시드로 계속 동작(빈 화면 금지).
- 신인의 위키 사진이 없음 → 이름 플레이스홀더(엉뚱한 사진 금지).
- 같은 인물이 여러 항목으로 중복 → 중복 제거.
- 그룹↔개인 혼재(시드가 "그룹 멤버" 단위) → 개인 단위로 정규화.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 음원 월드컵의 후보 풀을 **현재 음악 차트 실데이터**에서 구성해야 한다(곡명·아티스트).
- **FR-002**: 시스템은 인물 월드컵(가수/아이돌)의 후보 풀을 **현재 인물 평판 순위 실데이터**에서 구성하고, 최근 급상승/신인을 최소 1명 포함해야 한다.
- **FR-003**: 음원 풀은 **매일 1회(KST 09시 기준)** 갱신되고 그날 안엔 안정적이어야 한다. 인물 풀은 **월 1회** 수준으로 갱신.
- **FR-004**: 외부 소스는 서버가 런타임에 직접 호출하지 않는다. 시드는 **별도 산출물(시드 파일)**로 준비되어 서버가 읽어 쓴다.
- **FR-005**: 시드 부재/손상/소스 실패 시 시스템은 **기존 생성 방식으로 폴백**해 앱이 정상 동작해야 한다(되는 척 금지).
- **FR-006**: 인물 월드컵은 **성별을 정확히 분류**해 m/f 풀을 구성하고, 그룹 시드는 개인 단위로 펼치며, 중복을 제거해야 한다.
- **FR-007**: 후보 이미지는 **정확한 본인 사진**을 보이고(엄격 매칭), 없으면 이름 플레이스홀더를 보여야 한다(틀린 얼굴/빈 박스 금지).
- **FR-008**: 월드컵 진입 시 후보·사진이 **콜드 생성 대기 없이 빠르게** 떠야 한다(풀 캐시 + 사진 프리워밍).
- **FR-009**: 시드 갱신 메커니즘은 자동 시도하되, 자동 실행 환경에서 외부 소스 미도달 시 **수동/주기 갱신으로 폴백** 가능해야 한다(갱신 실패가 서비스 중단으로 이어지지 않음).

### Key Entities *(include if feature involves data)*

- **음원 시드(Song Pool)**: 현재 차트 기반 곡 목록 — 곡명, 아티스트, (가능 시) 발매/순위/급상승 표시.
- **인물 시드(Person Pool)**: 현재 평판 순위 기반 인물 목록 — 이름, 소속(그룹), 순위, 성별, 신인 여부.
- **가공된 월드컵 후보**: 시드에서 파생 — 표시 이름 + 이미지 식별자(정확 매칭용) + (인물) 성별. 16강 토너먼트가 소비.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 음원 월드컵 16강이 **현재 차트의 실제 곡**으로 100% 채워진다(플레이스홀더/가짜 곡 0).
- **SC-002**: 인물 월드컵 후보에 **최근 급상승/신인이 ≥1명** 포함된다(고정 톱티어 수렴 탈출 — 전일/전월 대비 신규 인물 등장).
- **SC-003**: 풀은 **하루(음원)·한 달(인물) 동안 안정적**이고, 경계 시점(09시/월초)에 갱신된다 — 같은 날 재진입 시 재생성 없음.
- **SC-004**: 성별 분류 정확도 **100%**(m 풀에 여성/ f 풀에 남성 혼입 0).
- **SC-005**: 풀 캐시 상태에서 진입 시 첫 대결 화면이 **콜드 LLM 대기 없이** 뜨고, 사진은 짧은 시간 내 표시(긴 딤 없음).
- **SC-006**: 시드/소스 실패를 인위로 유발해도 앱이 **오라클 PASS**(깨짐/죽은 컨트롤 0)로 폴백 동작한다.

## Assumptions

- 외부 소스(현재 차트·인물 평판)는 **Claude(클라이언트) 측 도구로만** 접근 가능하고 서버는 직접 못 부른다 → 시드 파일 매개가 유일한 견고한 경로(검증됨).
- 차트·평판은 천천히 변하므로 일/월 갱신으로 충분하다(분 단위 실시간 불필요 — 사용자 합의).
- 기존 이미지 신뢰성 자산(엄격 매칭 + ko-first 위키 + 프리워밍)을 재사용한다.
- v1 범위는 **가수/아이돌 + 음원**. 배우/예능 인물 월드컵은 음악 외 소스가 필요해 후속(별도 평판 소스).
- 시드 자동 갱신이 실행 환경 제약으로 불안정할 수 있어, 수동/주기 갱신 폴백을 전제로 한다.
