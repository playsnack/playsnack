# Simon 따라하기 `game-simon`  ·  game

**Verdict:** needs-fix  ·  **Mode:** single

## 주제 매력도
기억력 게임은 누구나 즉시 이해하는 보편적 캐주얼 장르다. "사이먼"(빛나는 순서 따라하기)은 수십 년 검증된 포맷이고, 짧은 한 판이 10~30초로 끝나 휘발성 스낵에 완벽히 맞는다. "내 최고 기록 몇 라운드?"라는 자기경쟁 후크가 강하고 재도전 욕구를 자극한다. 주제 자체는 충분히 매력적이라 변경 불필요. 다만 RED/BLUE/GREEN/YELLOW 영문 라벨은 KR 정체성에 어긋나 빨강/파랑/초록/노랑 또는 라벨 제거(색만으로 충분)가 더 낫다.

## 레퍼런스 (검증된 인기 포맷 모방)
- **모방 대상:** Simon (전자 기억 게임) / 모바일 'Simon Says' 류 앱
- **구조 100% 복제:** 검증된 사이먼 룰 100% 모방: (1) 시스템이 4색 패드 중 하나를 점등 → 매 성공마다 시퀀스 끝에 색 1개 추가, (2) 점등이 끝나면 플레이어가 같은 순서로 탭, (3) 한 번이라도 틀리면 즉시 게임오버, (4) 도달한 라운드=점수, 최고 기록 갱신. 이 시퀀스-점등→따라탭→1단계 증가→실패시 종료 흐름이 핵심.
- **우리 콘텐츠/디자인:** 콘텐츠/비주얼만 우리 것: 4색 패드를 블랙(#0b0c0e) 배경 위 네온 점등(라임 #d9ff00 액센트는 시작/재시작 CTA에만), 점등 시 채도 풀로 빛나고 평소엔 어둡게. KR 카피(순간 기억력을 깨워보세요 / 여기까지 기억했어요), 결과 화면 라운드 카운트 + 🧠 이모지. 영문 RED/BLUE 라벨은 색만으로 대체 권장.

## 목적
대기 시간 0의 순간 기억력 테스트. 빛나는 색 순서를 외워 그대로 따라 탭하며 '내가 몇 라운드까지 버티나'를 겨루는 자기경쟁 스낵 게임. 짧고 중독적인 한 판으로 즉석 소비형 재미를 준다.

## 핵심 루프
시스템이 보여준 색 점등 순서를 기억해 같은 순서로 패드를 탭하면 다음 라운드에 색이 1개 늘고, 틀리면 게임오버되어 도달 라운드가 기록된다.

## 시나리오
1. 시작 화면 진입 → 'Simon 기억 게임' 타이틀, 설명, 최고 라운드 0, 라임색 '시작' 버튼 표시
2. '시작' 탭 → play 화면 전환, round=1, 첫 색 1개가 점등(showing=true), '순서를 보여주는 중…' 표시
3. 점등 종료(약 650ms) → showing=false, '이제 그대로 탭하세요' + '1번째 패드를 고르세요' 안내, 입력 0/1
4. 사용자가 점등됐던 색 패드를 탭 → 정답이면 inputIndex 증가, 시퀀스 끝까지 맞히면 round+1 & 색 1개 추가 후 다시 점등
5. 오답 패드 탭 → 즉시 bestRound 갱신 후 result 화면으로 전환
6. result 화면 → 🧠, '여기까지 기억했어요', 이번 기록 N라운드 / 최고 기록 M라운드 표시
7. '다시 시작' 탭 → seq 초기화, round=1, 새 색 순서로 play 재시작

## 성공 기준
- 시작/플레이/결과 3개 화면이 또렷이 읽히고 한국어 카피가 자연스럽다
- 4색 패드가 play 영역(402px)을 균등히 채우는 큼직한 4분할 그리드로 보여 탭하기 쉽다
- 점등 애니메이션이 한 색씩 또렷이 켜졌다 꺼져 순서를 눈으로 따라갈 수 있다
- 라운드/입력 진행 카운터가 실시간으로 보이고 변한다
- 오답 즉시 게임오버, 정답 누적 시 라운드 증가 — 사이먼 룰이 정확히 동작한다
- 최고 기록이 판 간 유지·갱신되어 재도전 동기를 준다
- 어떤 화면에서도 텍스트 겹침·잘림·빈 검은 영역이 없다
