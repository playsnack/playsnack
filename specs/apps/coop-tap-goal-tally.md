# 다 같이 게이지 채우기 (멀티 · 세션)  —  id: coop-tap-goal-tally

## 한 줄
경쟁 말고 협동 — 방 전체가 하나의 게이지를 제한시간 안에 같이 채운다.

## 왜 인기 (근거)
"내 탭 하나가 모두의 게이지에 즉시 보태진다"는 집단 소속감은 Twitch Hype Train / 유튜브 라이브 동접 카운트다운 / 콘서트 응원봉 떼창에서 반복 검증된 강력한 포맷이다. 한국은 떼창·총공(스밍)·실시간 동접 카운트 문화가 세계 최강이라 "다 같이 채운다"는 협동 목표의 친화도가 매우 높다. 경쟁(누가 더)이 아니라 협동(우리가 다 같이)이라 패배자가 없고, 2~8명 소규모 방에서도 모두가 같은 편이 되어 마지막 몇 초의 "조금만 더!" 긴장과 달성 카타르시스를 30초~1분 안에 휘발적으로 함께 소비한다. 핵심 차별점: 경쟁 레이스(score/tap)와 달리 개인 순위표가 없고, 단 하나의 공동 막대 + 제한시간 + 성공/실패라는 단순·명료한 협동 루프다.

## 세션 흐름 (화면별)
- **대기실(lobby)**: 방에 들어온 사람들의 roster(닉네임 + 인원수 N), 게임 한 줄 설명("다 같이 게이지를 시간 안에 채우자!"), 이번 판 목표/제한시간 미리보기(예: "목표 인원수×40탭 · 30초"), 그리고 라임 **시작하기** 버튼. 누구나 시작 가능(host 고정 아님). 입장/퇴장 시 roster가 실시간 갱신된다.
- **카운트다운**: 시작하기 → 서버가 sessionPhase=countdown 브로드캐스트 → 전 클라이언트가 동시에 3·2·1 큰 숫자를 보여준다. 이때 공동 게이지/총 탭수는 0으로 리셋된 채 대기.
- **플레이(play)**: **싱글라운드**(한 번의 play 페이즈, multiRound=false). 화면 중앙에 큰 라임 탭존 + 그 위에 하나의 공동 진척 막대(coopTotal / goal), 상단에 남은 시간(초), 막대 아래 "현재 N / 목표 M (P%)"와 "내가 보탠 탭: k". 탭존을 누구든 누르면 +1이 서버로 가고, 서버 합산값 coopTotal이 모두의 막대를 실시간으로 차오르게 한다. 여럿이 동시에 연타하면 막대가 눈에 띄게 가속해 차오르며 "다 같이 만든다"는 군중감이 산다. 남은 시간 0 또는 coopTotal>=goal 도달 시 자동으로 결과로 전환.
- **결과(result)**: 성공/실패 리빌 — coopTotal>=goal이면 "🎉 다 같이 성공!" 라임 축하 연출(전원 동일 화면), 미달이면 "아쉽! 조금 모자랐어요" + 도달률(P%). 함께 **총 탭수**(coopTotal)와 목표·달성 여부를 크게 보여주고, (선택) "이번 판 내가 보탠 탭"도 표기. 라임 **다시** 버튼 → 서버가 새 목표/타이머를 잡고 카운트다운으로 복귀(휘발적 반복).

## 컨트랙트 매핑
- **주 컨트랙트 = `tally`** (co-op +1 to one total). 개인 순위표(raceBoard) 없음 — 단일 공동 합계만.
- **보조 = `roster`** (대기실 인원/닉네임), **`reactions`**(선택, 응원 이모지).
- host event emit 시점:
  - **start**: 대기실에서 시작하기 탭 → `emitHostEvent('start')`. 서버가 sessionPhase=countdown→(N초 후)play로 전환, coopTotal=0·myTaps=0 리셋, goal·deadline 산정 후 setVar 브로드캐스트.
  - **tally**: play 중 탭존 누를 때마다 → `emitHostEvent('tally', { delta: 1 })`. 로컬은 즉시 myTaps+1로 낙관적 갱신, 서버는 모든 클라의 delta를 합산해 coopTotal을 setVar로 전체 동기화. (즉시-피드백 규칙: 로컬 탭 카운트는 서버 왕복을 기다리지 않고 바로 반응.)
  - **vote / score / tap**: 사용하지 않음 (협동 단일 게이지라 개인 투표/점수/레이스 불필요).
- **라운드 필요 여부**: 불필요. **SINGLE-round** 세션 — 한 판 = 한 번의 play 페이즈. 서버는 round를 advance하지 않고, "다시"는 라운드 진행이 아니라 같은 세션의 새 판(목표/타이머 재산정)일 뿐.

## 콘텐츠
- 콘텐츠팩(서버-권위 질문/매치업/후보/정답) **불필요**. 이 게임은 정답·질문·매치업이 없는 순수 인터랙션 협동 게임이라 모든 클라가 본질적으로 동일(공동 게이지 하나)하다. roundContent 브로드캐스트가 필요 없다.
- 대신 서버가 매 판 산정/브로드캐스트하는 **세션 파라미터**(콘텐츠팩이 아닌 동적 설정값):
```json
{
  "sessionPhase": "lobby | countdown | play | result",
  "goal": 280,            // 동적 권장: rosterCount * tapsPerPlayer(예 40), 스낵 규모로 30초~1분 내 달성 가능
  "tapsPerPlayer": 40,    // 인원 기반 목표 산정 계수
  "durationMs": 30000,    // play 제한시간
  "deadline": 0,          // 서버 기준 종료 timestamp(= play 시작 + durationMs), 클라 타이머 싱크용
  "coopTotal": 0,         // 서버 합산 공동 탭수 (tally 누적, setVar로 전체 동기화)
  "rosterCount": 0,       // 현재 방 인원 (목표 산정·대기실 표시)
  "result": "success | fail | null"  // result 페이즈에서 coopTotal>=goal 판정
}
```
- 카피(우리가 채움, 블랙#0b0c0e+라임#d9ff00 톤): 대기실 설명("다 같이 게이지를 시간 안에 채우자!"), 탭존 라벨("탭해서 힘 보태기"), 결과 성공/실패 문구. roster 기반(닉네임·인원수)이며 외부 문제 데이터는 없음.
- 주의(레퍼런스 PRD 교훈 반영): goal은 **인원 기반 동적**으로 잡아 막대가 실제로 눈에 띄게 차오르게 한다(고정 10,000 같은 비현실 목표 금지 — 진척감 0 방지). 막대 fill은 최소 1px 보장, 마일스톤(50%/90%) 펄스 연출로 작은 진척도 체감.

## 성공 기준
- 탭 즉시(로컬 데드타임 0) 공동 막대·"현재 N"·"내가 보탠 탭"이 시각적으로 반응한다.
- 한 클라의 탭이 서버 합산을 거쳐 **다른 클라 화면의 coopTotal/막대에 1~2초 내 반영**된다(멀티 동기화).
- goal이 인원 기반 동적이라 2~8명이 30초~1분 내 실제로 달성 가능하고, 막대가 눈에 띄게 차오른다(0% 고정 금지).
- 남은 시간이 매초 줄고, 시간 종료 또는 목표 도달 시 전원이 동시에 result로 전환되어 동일한 성공/실패 리빌을 본다.
- 모든 텍스트가 겹치거나 줄바꿈으로 깨지지 않고 390x844 한 화면 안에 들어온다.

## QA 검증 시나리오 (멀티클라이언트)
3개 클라이언트(A·B·C)를 같은 `/p/tpl-coop-tap-goal-tally` 링크로 연다.
- [ ] **QA1 입장 & roster** — A·B·C가 차례로 링크 입장 → 각 화면 대기실에 인원수가 1→2→3으로 늘고 roster에 3명의 닉네임이 모두 보이면 **PASS**. (한 클라가 나가면 인원수가 줄어드는지도 확인.)
- [ ] **QA2 시작 & 카운트다운 싱크** — A가 시작하기 탭 → A·B·C 세 화면 모두 거의 동시에 3·2·1 카운트다운이 뜨고, 카운트 종료와 함께 셋 다 play 화면(막대 0%, 남은 시간 30초)으로 전환되면 **PASS**. (B·C가 시작 버튼을 누르지 않았는데도 server 브로드캐스트로 같이 넘어가야 함.)
- [ ] **QA3 협동 탭 합산** — play 중 A가 5번, B가 3번 탭 → A·B·C 세 화면 모두에서 공동 막대 "현재"가 **8**(=5+3) 부근으로 동일하게 차오르고, A 화면 "내가 보탠 탭=5", B 화면 "내가 보탠 탭=3"으로 각자 기여분이 다르게 보이면 **PASS**. (공동 합계는 셋 다 같고, 개인 기여만 달라야 함. 막대 fill 폭이 실제로 늘어나야 함 — 0px 고정이면 FAIL.)
- [ ] **QA4 목표/시간 종료 → 결과 리빌** — 셋이 함께 연타해 coopTotal>=goal 도달(또는 30초 경과) → A·B·C 세 화면이 동시에 result로 넘어가고, 달성 시 셋 다 "🎉 다 같이 성공!" + 동일한 총 탭수를, 미달 시 셋 다 "아쉽!" + 동일 도달률(%)을 보이면 **PASS**. (성공/실패 판정과 총 탭수가 세 화면에서 일치해야 함.)
- [ ] **QA5 다시 → 재세션** — result에서 누구든 다시 탭 → 새 goal/타이머로 카운트다운이 다시 시작되고 coopTotal·myTaps가 0으로 리셋된 채 셋 다 새 판에 진입하면 **PASS**.
