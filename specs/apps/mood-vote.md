# 오늘 기분 투표 `mood-vote`  ·  reaction

**Verdict:** needs-fix  ·  **Mode:** multi (vote — 여러 익명 참여자가 같은 질문에 투표하고 막대/퍼센트로 실시간 집계 공유(votesByOption + emitHostEvent 'vote'로 서버 합산, 우상단 참여자 수 표시).)

## 주제 매력도
"오늘 기분"은 누구나 0.5초 안에 자기 답을 갖는 보편 주제다. 정답·실력이 필요 없어 진입장벽이 0이고, "나만 이런가?" 하는 공감 욕구를 즉시 충족한다. 다만 5개 고정 보기(좋아요/평온/피곤/울적/설레)는 무난하지만 평범하다. KR 스낵 감성을 살리려면 매일 바뀌는 한 줄 질문형(예: "지금 너의 텐션은?" 후보=ㄱ삐침/ㅈㄴ졸림/풀충전/번아웃/설렘주의보)으로 신조어를 섞으면 공유 욕구가 훨씬 올라간다.

## 레퍼런스 (검증된 인기 포맷 모방)
- **모방 대상:** 인스타그램 스토리 투표 스티커 / 트위터 폴(Poll)
- **구조 100% 복제:** 즉석 단일선택 투표 + 탭 즉시 실시간 막대 집계 + 퍼센트 표시 + 재탭 변경. 결과 화면을 따로 두지 않고 '투표=결과 동시 노출' 한 화면 구조를 100% 모방.
- **우리 콘텐츠/디자인:** 질문/보기 콘텐츠는 KR 기분 신조어로 새로 채우고, 비주얼은 블랙(#0b0c0e)+라임(#d9ff00) 톤. 선택 보기는 라임 풀필 막대, 내 선택 라벨은 다크 텍스트로 반전.

## 목적
지금 기분을 한 번 탭하면 즉시 전체 분포(막대+퍼센트)가 뜨는 초경량 공감 투표. 소비자는 '나만 이런가?'를 0.5초 안에 확인하고, 다수와 같으면 안심, 소수면 개성을 느끼는 가벼운 휘발성 재미를 얻는다.

## 핵심 루프
기분 보기 하나를 탭 → 그 즉시 내 선택이 라임으로 반전되고 전체 실시간 퍼센트 막대가 갱신 → 마음 바뀌면 다른 보기 재탭해 변경.

## 시나리오
1. 사용자가 링크를 연다 → 질문/부제/5개 기분 보기가 0% 막대로 즉시 표시(데드타임 0)
2. '평온해요' 탭 → 해당 보기가 라임으로 반전, myVote='o1' 세팅, vote 호스트이벤트 전송
3. 서버가 votesByOption 갱신 → setVar로 전체 클라에 동기화, 모든 막대 width/퍼센트 즉시 재계산
4. 혼자일 때 선택 보기는 100% 풀필로 표시(스샷1)
5. 다른 참여자가 '좋아요' 투표 → 막대가 90%/10%로 실시간 재분배(스샷2), 우상단 참여자 카운터 증가
6. 마음이 바뀌면 다른 보기 재탭 → myVote 변경, 분포 즉시 갱신
7. 계속 열어두면 들어오는 표에 따라 막대가 살아 움직이며 공감/의외 결과를 관전

## 성공 기준
- 탭 즉시(애니 지연 없이) 막대와 퍼센트가 갱신돼 snappy하다
- 내 선택이 라임 반전으로 한눈에 구분되고, 그 위 텍스트(라벨·퍼센트)가 모두 또렷이 읽힌다
- 5개 보기 라벨/이모지/퍼센트가 겹치지 않고 한 화면에 들어온다
- 퍼센트 합이 항상 의미상 100%에 수렴하고(반올림 오차 제외) 표 수와 일치한다
- 여럿이 투표하면 우상단 참여자 수와 분포가 실시간 동기화된다
- 기분 보기 카피가 한국어로 자연스럽고 이모지가 감정과 일치한다

## 현재 깨짐 (진단)
- **[high]** 선택된 보기가 라임으로 풀필될 때 퍼센트 텍스트가 사라진다. pct.color가 항상 라임(#d9ff00)으로 고정인데 선택 막대 색도 라임이라 lime-on-lime로 안 보임. 스샷3에서 '평온해요' 100% 풀필 막대 위 '100%'가 완전히 사라짐.
  - 근거: shots/mood-vote-3.png: 평온해요 행이 통째로 라임 풀필인데 우측 퍼센트 숫자가 없음. 문서 line 332/348 label color는 반전 처리하지만 pctN.color 바인딩은 없어 항상 #d9ff00(line 126,168,... 초기값) 유지.
  - 수정: 각 상태 바인딩에 pctN.color도 추가: myVote==='oN' ? '#0b0c0e' : '#d9ff00' (라벨 반전과 동일하게).
- **[medium]** 소수 퍼센트(예 10%)일 때 막대가 너무 짧아 세로 알약(pill)처럼 보이고 가로 진행바로 안 읽힌다. Math.max(6, ...)로 최소폭 6px이라 10%여도 cornerRadius14가 양쪽에 다 먹어 둥근 알약이 됨.
  - 근거: shots/mood-vote-2.png: '좋아요' 10% 막대가 좌측에 노란 세로 알약 형태로 막대 인지가 안 됨. bar0 width=Math.max(6,...) line 329, cornerRadius 14 line 101.
  - 수정: 막대 최소폭을 키우거나(예 24), 막대 cornerRadius를 컨테이너보다 작게/좌측만 라운드 처리해 진행바로 읽히게.
- **[low]** 선택 막대가 100% 미만일 때(스샷2 90%) 라임 풀필이 컨테이너 끝까지 안 차서 우측에 다크 갭이 남고 그 위에 퍼센트가 떠 다소 어색. 막대 위 텍스트와 막대 끝 경계가 정렬되지 않음.
  - 근거: shots/mood-vote-2.png: 평온해요 90% 막대 우측 끝과 '90%' 텍스트 사이 정렬이 어긋남.
  - 수정: 의도된 동작이면 무방. 다만 선택 보기의 퍼센트 텍스트는 막대 안에 들어오도록 위치 보정 고려.
