# 상식 OX 퀴즈 `quiz-ox`  ·  quiz

**Verdict:** needs-fix  ·  **Mode:** single

## 주제 매력도
상식 OX 퀴즈는 누구나 즉시 참여 가능한 검증된 포맷이지만, 현재 문항(태평양/심장 위치/물 어는점/한글 창제/빛vs소리)은 초등 교과서 수준이라 KR 성인 소비자에게는 너무 뻔하고 휘발성 재미가 약하다. 더 매력적인 주제로 바꾸면 좋다: "요즘 신조어 OX", "K-드라마/연예계 사실 OX", "은근히 헷갈리는 생활상식 OX(예: 라면 먼저 넣기 vs 스프 먼저)", "맞춤법 OX" 같은 '아는 줄 알았는데 틀리는' 함정형 문항이 공유 욕구를 자극한다. OX 포맷 자체는 살리되 문항을 '직관 vs 정답이 어긋나는' 트릭형으로 채워야 한다.

## 레퍼런스 (검증된 인기 포맷 모방)
- **모방 대상:** 옛날 학교 OX 골든벨 / 카카오톡식 OX 퀴즈 (TV OX 퀴즈쇼 포맷)
- **구조 100% 복제:** 검증된 OX 퀴즈쇼 룰을 100% 모방: (1)문제 제시 → (2)O 또는 X 단일 탭으로 즉답 → (3)즉시 정/오답 피드백 + 정답 공개 → (4)다음 문제 → (5)N문제 종료 후 최종 점수/등급. 진행바(현재 문제/총 문제), 누적 점수, 라운드 진행이라는 퀴즈쇼의 핵심 진행 흐름을 그대로 가져옴.
- **우리 콘텐츠/디자인:** 콘텐츠는 KR 함정형 OX 문항으로 새로 채우고(직관과 정답이 어긋나는 헷갈리는 상식/신조어/생활팁), 디자인은 블랙(#0b0c0e)+라임(#d9ff00) 톤, O/X 큰 탭 카드, StatCard 점수판으로 우리 비주얼화. 구조=퀴즈쇼, 콘텐츠·비주얼=우리 것.

## 목적
지하철/대기 같은 빈 시간에 열어 "이거 O일까 X일까?" 직관으로 5문제를 1분 안에 풀고 점수를 확인하는 즉석 상식 테스트 스낵. 매 문제 즉시 정/오답이 떠서 '아 맞혔다/틀렸다'는 작은 도파민을 빠르게 반복 소비한다.

## 핵심 루프
문제를 읽고 O 또는 X 카드를 한 번 탭 → 즉시 정/오답 피드백과 정답 공개 → '다음 문제'로 넘기며 5문제 반복 → 최종 점수.

## 시나리오
1. 사용자가 앱을 연다 → quiz state 초기화: 문제 1/5, 점수 0점, Q1 문제 텍스트, O/X 카드 노출(feedbackCard/nextBtn 숨김)
2. 사용자가 문제를 읽고 O 카드를 탭 → answered=true, selected='O', 정답이면 score+1, feedbackCard와 '다음 문제' 버튼이 나타남
3. 앱이 정/오답을 즉시 표시 → '정답!'(라임) 또는 '오답!'(빨강)+'정답은 X예요' 안내, 동시에 정답 옵션 카드가 라임으로 강조됨
4. 사용자가 '다음 문제' 탭 → qIndex+1, answered/selected 리셋, Q2 문제로 전환, 점수판은 누적 점수 반영
5. 2~3단계를 Q5까지 반복 (매 문제 점수 카드가 누적 갱신되어야 함)
6. Q5에서 '다음 문제' 탭 → result state로 전환: 트로피 뱃지, '완료!', 최종 점수 'N / 5점', 점수별 격려 메시지
7. 사용자가 '다시하기' 탭 → 모든 변수 리셋 후 quiz state Q1로 복귀

## 성공 기준
- O/X 카드 탭이 매번 즉시 응답하고(데드타임 0), 정/오답 피드백이 같은 화면에서 바로 뜬다
- 점수판(점수 N점)이 정답을 맞힐 때마다 실제로 누적되어 눈에 보인다 — 정답 피드백과 점수 표시가 일치한다
- 문제 텍스트가 2줄까지 깨짐 없이 카드 안에 들어오고, O/X·피드백·버튼이 한 화면에 다 보인다
- 칩/라벨 텍스트가 자기 컨테이너(pill) 밖으로 넘치지 않는다
- 퀴즈 정답이 실제 사실과 일치한다(태평양=O, 심장 오른쪽=X 등) — 오답 안내의 정답도 정확
- 5문제 종료 후 결과 화면 점수가 실제 맞힌 수와 같고, 다시하기가 완전 초기화된다

## QA 검증 시나리오
- [ ] **QA1** O 카드, X 카드, 다음 문제, 다시하기 버튼이 모두 탭에 반응하는가 → `optO/optX 탭 시 answered=true로 전환되고 피드백 노출, nextBtn 탭 시 다음 문제 또는 결과로 전환, retryBtn 탭 시 Q1 초기화`
- [ ] **QA2** 정답을 맞힌 직후 점수 카드(scoreStat.value)가 실제로 +1 되어 표시되는가 → `Q1을 정답 처리하면 점수판이 '0점'→'1점'으로 즉시 변경. (현재 스크린샷에서 정답 피드백 후에도 0점으로 남아 있어 FAIL 의심)`
- [ ] **QA3** 진행 표시(progressStat.value)가 문제마다 갱신되는가 → `'1 / 5'→'2 / 5'… Q5에서 '5 / 5'`
- [ ] **QA4** 문제 텍스트가 카드 안에서 줄바꿈되며 화면 밖으로 안 나가는가 → `2줄 이내로 중앙 정렬, 28pt 텍스트가 width 318 안에서 wrap, 잘림 없음 (현재 OK)`
- [ ] **QA5** COMMON SENSE 칩 텍스트가 pill 경계 안에 들어오는가 → `칩 라벨이 한 줄로 pill 안에 들어감. (현재 'COMMON SENSE'가 2줄로 wrap되어 height 30 pill 밖으로 넘침 → FAIL)`
- [ ] **QA6** 퀴즈 콘텐츠의 정답이 사실과 일치하는가 → `태평양=O(true), 심장 오른쪽=X(false), 물 0도=O, 한글 세종대왕=O, 빛>소리=O 모두 정확 (현재 answers 배열과 사실 일치, OK)`
- [ ] **QA7** 결과 화면 최종 점수가 실제 맞힌 개수와 같은가 → `finalScore가 '맞힌수 / 5점', 메시지가 점수 구간(5/3+/그외)에 맞게 표시`
- [ ] **QA8** 다시하기 후 점수·진행·피드백이 완전 초기화되는가 → `qIndex=0, score=0, answered=false, '문제 1/5', '점수 0점', 피드백/버튼 숨김`

## 현재 깨짐 (진단)
- **[high]** 정답을 맞힌 뒤에도 점수판이 0점으로 남아 누적이 화면에 반영되지 않음
  - 근거: quiz-ox-2.png: 피드백이 '정답!'(라임)로 표시되었는데 좌상단 점수 StatCard는 여전히 '0점'. quiz-ox-3.png: Q2로 넘어갔는데도 점수가 '0점'. 구조상 optO 트리거가 score+1을 하고(quiz-ox.bite.json:439-447) scoreStat.value 바인딩이 `${score}점`이지만(line 410), StatCard 인스턴스의 propValue가 setVar 후 재전파되지 않는 것으로 보임. MEMORY의 '바인딩 재전파 안 됨' 이슈와 일치. 정답인데 점수가 안 오르면 게임의 핵심 보상이 깨짐.
  - 수정: scoreStat.value를 컴포넌트 인스턴스 propValue 바인딩이 아니라 StatCard 내부 텍스트 레이어를 직접 가리키는 state-level 바인딩으로 연결하거나, score 변경 후 runtime이 인스턴스 prop을 재평가하도록 바인딩 경로를 수정. 정답/오답 피드백 표시와 점수 갱신이 같은 프레임에 일어나는지 E2E로 검증.
- **[medium]** 'COMMON SENSE' 칩 텍스트가 pill 안에 안 들어가고 2줄로 넘쳐 둥근 pill 밖으로 삐져나옴
  - 근거: quiz-ox-1/2/3.png 모두: 칩 라벨 'COMMON SENSE'가 'COMMON'+'SENSE' 2줄로 wrap되며 height 30 고정 pill(quiz-ox.bite.json:775) 경계를 벗어나 위아래로 잘려 보임. KR 앱에 영문 라벨도 톤 부조화.
  - 수정: 칩 라벨을 짧은 한글 한 단어로 교체('상식' 등)하거나 chip을 width hug + 한 줄 강제(nowrap)로. 폰트 13pt 기준 한 줄에 맞는 길이로 콘텐츠 제한.
- **[low]** 문항이 초등 교과서 수준으로 너무 뻔해 휘발성 재미·공유 동기가 약함
  - 근거: questions 배열(quiz-ox.bite.json:36-41): 태평양/심장/물 어는점/한글/빛 — 모두 정답이 자명. 틀릴 사람이 거의 없어 '아 틀렸다'의 도파민이 안 생김.
  - 수정: 직관과 정답이 어긋나는 함정형 KR 문항으로 교체(신조어/맞춤법/생활상식 트릭). 모범 템플릿이므로 콘텐츠 품질을 끌어올려야 AI 생성 본보기로서 가치가 있음.

## 멀티 변형 아이디어 (별도 앱)
OX 퀴즈는 '실시간 OX 골든벨'로 만들면 강력하다. 진행자가 같은 문제를 동시에 띄우고 모두가 O/X로 답하면, 화면 양쪽에 O 쪽/X 쪽 인원이 실시간 집계(live tally)되고 라운드마다 오답자가 탈락(또는 점수 누적)해 마지막 1인이 우승. 메커니즘=live-race + spectate. vote 컨트랙트가 이미 있으니 OX 2지선다 집계로 확장 가능.
