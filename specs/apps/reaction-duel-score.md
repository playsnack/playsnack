# 반응속도 대결 (멀티 · 세션)  —  id: reaction-duel-score

## 한 줄
화면이 초록으로 바뀌는 순간 가장 먼저 탭 — 헛스윙은 파울.

## 왜 인기 (근거)
- **즉각 보편 룰**: "초록 되면 눌러"는 설명 0초. 전 세계 reaction-time 테스트(Human Benchmark, 휴먼벤치마크)가 수억 회 플레이되는, 검증된 micro-game 포맷.
- **휘발성/스낵 적합**: 한 라운드가 1~5초. 같은 링크에 모인 2~8명이 "야 다시!" 하며 best-of-N으로 무한 리매치 — 자리에서 즉시 도파민.
- **긴장 설계**: 랜덤 딜레이 + "초록 전 탭=파울" 규칙이 안달/페이크아웃을 만든다. 헛스윙 한 명이 나오면 폭소 — 오프라인 모임에서 바로 터지는 룰.
- **공정한 동시성**: 서버가 GO! 시점을 한 번에 broadcast → 모든 클라가 같은 순간 초록을 본다(네트워크 편차는 라운드 다득점/best-of-N으로 희석).

## 세션 흐름 (화면별)
- **대기실(lobby)**: 방에 들어온 사람 목록(roster, 닉네임 칩 2~8개) + "총 N명" 카운터 + **시작하기** 버튼(방장/먼저 누른 사람). 하단에 룰 한 줄("초록 되면 제일 먼저 탭! 초록 전 탭은 파울"). best-of-N 표시(예: 5판 3선).
- **카운트다운**: 3 · 2 · 1 풀스크린 숫자, 서버 동시 broadcast로 모두 동기화. "준비…" 카피.
- **플레이(play) — MULTI-ROUND (best-of-N)**: 
  - 화면 전체가 **빨강 = WAIT**("기다려…"). 이때 탭하면 **파울(too soon)** → 이번 라운드 즉시 패. 빨강 화면에 "헛스윙!" 피드백.
  - 서버가 **랜덤 딜레이(1.5~5s)** 후 한 번에 `roundGo` broadcast → 화면 전체 **초록 = GO!**("지금!").
  - 초록 전환 후 **첫 탭 = 라운드 승**. 클라는 탭 즉시 자기 반응시간(ms)을 표시("0.214s"), 서버는 라운드 승자 1명을 확정해 broadcast.
  - 라이브 표시: 상단에 **라운드 N / N**, **누적 점수판(raceBoard)** — 각 플레이어 닉네임 + 라운드 승수. 라운드 결과("○○ 승, 0.18s")가 잠깐 뜨고 다음 라운드 WAIT로 자동 진행.
  - 한 명이 best-of-N의 과반 선승을 채우면 세션 종료 → result.
- **결과(result)**: **최종 우승자 1명** 크게(👑 + 닉네임), 전체 점수판(라운드 승수 순 정렬) + 각자 **베스트 반응시간(ms)**. **다시** 버튼 → 점수 리셋 후 카운트다운으로 복귀(같은 roster 유지).

## 컨트랙트 매핑
- **사용 컨트랙트: `score`(per-player count → named leaderboard `raceBoard`)** + `roster`. 콘텐츠팩은 불필요(아래 콘텐츠 참고).
- host event emit 타이밍:
  - `start` — 대기실에서 **시작하기** 탭 시 1회. 서버: roster 확정 → countdown phase broadcast → 첫 라운드 WAIT 진입 + 랜덤 딜레이 타이머 시작.
  - `tap` — 플레이 중 플레이어가 화면을 탭할 때마다 emit(클라가 `tapClientTs`/현재 phase 동봉). 서버가 판정:
    - phase=WAIT에서 들어온 tap → 그 플레이어 **파울**(해당 라운드 무효/패).
    - phase=GO에서 **가장 먼저** 도착한 유효 tap → 라운드 승자, 해당 플레이어 `score` +1(`raceBoard` 갱신 broadcast).
  - `score` 컨트랙트는 서버가 라운드 승 확정 시 내부적으로 적용(클라가 직접 score를 올리지 않음 — 부정 방지). 라운드 종료 → 다음 라운드 content 재broadcast(WAIT 재진입 + 새 랜덤 딜레이) 및 per-round 상태 리셋.
- **라운드 필요: 예 (MULTI-ROUND).** 서버가 라운드를 진행하고 매 라운드 GO 타임스탬프/딜레이를 새로 잡아 rebroadcast. best-of-N 과반 도달 시 result phase broadcast.
- 서버가 GO 시점(`goServerTs`)을 broadcast하고, 반응시간 = (서버가 첫 tap 수신한 시각 − goServerTs)로 계산해 모든 클라 공정 비교(또는 클라 tapClientTs − goBroadcastTs를 서버가 정규화).

## 콘텐츠
- **콘텐츠팩 불필요.** 이 게임은 질문/매치업/후보가 없는 **순수 반응 게임** — "콘텐츠"는 서버가 라운드마다 생성하는 **랜덤 딜레이 값**뿐이다(server-authoritative).
- roster 기반(플레이어 닉네임이 곧 점수판 항목).
- 서버 라운드 상태(broadcast `roundContent` 대체용 `roundState`) 형식 제안(JSON):
```json
{
  "round": 2,
  "totalRounds": 5,
  "winsToClinch": 3,
  "phase": "wait",                 
  "waitDelayMs": 3200,             
  "goServerTs": null,              
  "foulPlayers": ["nick_A"],       
  "roundWinner": null              
}
```
- 세션 설정(시작 시 고정): `{ "bestOfN": 5, "winsToClinch": 3, "minDelayMs": 1500, "maxDelayMs": 5000 }`.
- `raceBoard`(score 컨트랙트 결과) 형식: `[{ "name": "nick_A", "wins": 2, "bestMs": 184 }, ...]`.

## 성공 기준
1. **동시성 정확도**: GO! 초록 전환이 모든 클라에서 broadcast 후 100ms 이내 표시(타임스탬프 기반 보정으로 승자 판정 편차 ≤ 30ms).
2. **파울 판정 정확**: WAIT phase 탭은 100% 파울 처리되어 해당 라운드 패(거짓 통과 0건). 초록 전환 후 가장 먼저 도착한 유효 tap만 승자.
3. **점수 동기화**: 라운드 승 직후 모든 클라의 `raceBoard` 승수가 1초 이내 동일하게 갱신.
4. **세션 완주**: best-of-N에서 한 명이 winsToClinch 도달 시 즉시 result 진입, 우승자/베스트 ms 정확 표시. **다시** → 리셋 후 카운트다운 복귀 100% 동작.
5. **체감 즉각성**: 탭→자기 ms 피드백 표시 ≤ 1프레임(낙관적 로컬 표시) — 서버 확정과 별개로 즉시 반응.

## QA 검증 시나리오 (멀티클라이언트)
**전제**: 클라이언트 3개(A·B·C)가 같은 `/p/tpl-reaction-duel-score` 링크 접속. best-of-5(3선승).

1. **입장 → roster 3**: A 접속 → 대기실에 A 칩 1개("총 1명"). B, C 차례로 접속.
   - PASS: A·B·C **세 화면 모두** roster에 닉네임 칩 3개 + "총 3명"이 동일하게 보임.
2. **시작 → 카운트 싱크**: A가 **시작하기** 탭.
   - PASS: A·B·C 세 화면이 **거의 동시에** 3·2·1 카운트다운 시작(육안 동기). 카운트 끝나면 세 화면 모두 **빨강 WAIT("기다려…")** 진입.
3. **파울(too soon) 판정**: WAIT(빨강) 중에 B가 먼저 탭.
   - PASS: B 화면에 "헛스윙!/파울" 표시, 이번 라운드 B는 승 불가. A·C 화면은 그대로 WAIT 유지(B의 조기 탭이 다른 사람의 라운드를 끝내지 않음).
4. **GO → 라운드 승 입력**: 랜덤 딜레이 후 세 화면이 동시에 **초록 GO!**. C가 가장 먼저 탭, 그 다음 A 탭.
   - PASS: 세 화면 모두 "○○(C) 승, 0.xxs" 라운드 결과 표시. 상단 `raceBoard`에서 **C 승수 = 1**로 세 화면 동일 갱신. 파울이었던 B는 0승 유지. 곧 다음 라운드 WAIT로 자동 진행.
5. **세션 종료(clinch) → 결과 + 다시**: 라운드 반복해 C가 3선승 도달.
   - PASS: A·B·C 세 화면 모두 result 진입 — 👑 **C 우승**, 점수판(승수 정렬)과 각자 베스트 ms 동일 표시. 아무나 **다시** 탭 → 점수 0으로 리셋되고 세 화면 모두 카운트다운으로 복귀(roster 3명 유지).
