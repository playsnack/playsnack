# 이상형 월드컵 `worldcup-ideal`  ·  worldcup

**Verdict:** broken  ·  **Mode:** single

## 주제 매력도
이상형 월드컵은 한국 인터넷에서 10년 넘게 검증된 초강력 바이럴 포맷이다 — "둘 중 하나만 골라" 토너먼트로 끝까지 가면 내 취향이 한 명으로 정리되는 쾌감이 핵심. 현재 theme=배우는 무난하지만 "배우"는 범위가 너무 넓어 호불호가 갈린다. 더 매력적인 변형: '여름 휴가지', '편의점 신상', '아이돌 남친짤', '국민 첫사랑상' 처럼 후보 간 우열 감정이입이 강한 좁은 주제가 클릭률이 높다. 단 어떤 주제든 후보 '사진'이 진짜여야만 성립하는 포맷이다(외모로 고르는 게임이므로).

## 레퍼런스 (검증된 인기 포맷 모방)
- **모방 대상:** 이상형 월드컵 (ideal-type worldcup, PIKU/이상형월드컵 사이트류의 원조 바이럴 포맷)
- **구조 100% 복제:** 16강 싱글 엘리미네이션 토너먼트 — 매 라운드 후보 2명을 1:1로 제시, 탭하면 승자 진출·패자 탈락. 16강(8경기)→8강→4강→결승(1경기)→우승자 1명. 진행 표시(16강·N번째 대결), 마지막에 우승자 결과 화면+다시하기. 이 구조는 worldcup-ideal.bite.json states.play 트리거(L72-87: roundSize 절반씩 감소, matchIndex 증가, winners 누적)에 정확히 구현돼 있고 동작한다.
- **우리 콘텐츠/디자인:** 콘텐츠=LLM이 KST 정시마다 후보 16명을 신선하게 생성(content.mjs L23-28, name=한국어/q=사진검색키워드). 디자인=블랙(#0b0c0e)+라임(#d9ff00) 톤, 풀블리드 후보 카드+하단 그라데이션 위 이름, 중앙 라임 VS, 우승 화면 라임 다시하기 버튼. 구조는 원조 그대로, 비주얼·후보풀은 우리 것.

## 목적
"둘 중 누가 더 좋아?"를 16번 누르다 보면 내 취향이 우승자 한 명으로 정리되는 즉석 토너먼트. 생각 없이 직관으로 탭만 하면 되고, 30초 안에 "오늘 내 이상형은 이 사람"이라는 공유하기 좋은 결과 한 장이 나온다 — 전형적인 휘발성 스낵 소비.

## 핵심 루프
두 후보 중 마음에 드는 쪽 카드를 탭 → 즉시 다음 대결로 교체 → 결승까지 반복 → 우승자 = 내 이상형.

## 시나리오
1. 앱 진입 → dataSource(/api/content?kind=worldcup&theme=배우)로 후보 16명 로드, current 배열 시드(content.mjs L74-76)
2. play 상태 초기 렌더 → 상단 '이상형 월드컵' 타이틀 + '16강 · 1번째 대결' 라벨, 위/아래 후보 카드(사진+이름), 가운데 라임 VS 표시
3. 사용자가 위 카드(optionA) 또는 아래 카드(optionB)를 탭
4. 앱: 선택한 후보를 winners에 누적, matchIndex+1 → 다음 두 후보로 카드/이름 즉시 교체, 라벨 '2번째 대결'로 갱신(L78)
5. 한 라운드 8경기가 끝나면(matchIndex >= roundSize/2-1) winners를 current로 승격, roundSize 절반(16→8→4→2), matchIndex 0 리셋, 라벨 '8강'으로 갱신(L77)
6. 결승(roundSize===2)에서 한 명을 고르면 champion 설정 후 result 상태로 전환(L74-75)
7. result 화면: '🏆 나의 이상형' + 우승자 사진(260x260) + 이름 + 서브카피 + 라임 '다시하기' 버튼 표시(sharedLayers L45-59)
8. '다시하기' 탭 → seed에서 current 복원, roundSize 16·matchIndex 0·champion null 리셋 후 play로 복귀(L97-104)

## 성공 기준
- 후보 카드의 사진이 '실제로 그 이름의 그 사람'이어야 한다 — 이상형 월드컵은 외모로 고르는 게임이라 사진 진실성이 곧 앱의 존재 이유
- 두 후보 사진이 매 대결마다 서로 다르고, 라운드마다 새 인물로 바뀌어 보여야 한다(같은 얼굴 반복 금지)
- 이름 텍스트가 사진 하단 그라데이션 위에 잘리지 않고 한 줄로 읽혀야 한다
- 탭이 즉각(데드타임 0) 다음 대결로 전환되고 라운드 라벨(16강/8강/4강/결승·N번째)이 정확히 증가
- 결승 후 우승자 화면이 사진+이름과 함께 정상 렌더, 다시하기가 처음 상태로 복귀
- 후보 풀 16명이 주제(배우)에 맞고 누구나 아는 실존 인물로 채워질 것

## QA 검증 시나리오
- [ ] **QA1** optionA/optionB 카드 탭이 실제로 응답하는가 → `각 탭마다 다음 대결로 즉시 전환(두 후보 이름이 모두 바뀜), 무반응 없음`
- [ ] **QA2** 라운드/진행 표시가 보이고 변하는가 → `roundLabel이 '16강·1번째'→'16강·2번째'... 8경기 후 '8강·1번째'로, 최종 '결승'까지 정확히 갱신(스크린샷에서 1→2→3번째 증가 확인됨)`
- [ ] **QA3** 후보 이름 텍스트가 겹치거나 잘리지 않고 화면 안에 들어오는가 → `위/아래 카드 하단의 이름이 그라데이션 위 한 줄로 완전히 읽힘 (스크린샷상 OK)`
- [ ] **QA4** 후보 사진이 이름과 일치하는 실제 그 인물인가 → `'김수현' 카드=배우 김수현 사진, '박보검' 카드=박보검 사진 등 — FAIL: 스크린샷 1/2/3 모두 위 슬롯은 동일한 한 남자, 아래 슬롯은 동일한 다른 남자로, 이름과 전혀 무관한 동일 사진 반복`
- [ ] **QA5** 두 후보 사진이 서로 다르고 라운드마다 새 인물로 보이는가 → `매 대결 4종(누적)으로 달라야 함 — FAIL: 단 2장의 사진만 모든 대결에서 반복`
- [ ] **QA6** 결승 후 result 화면이 우승자 사진+이름으로 정상 렌더되고 다시하기가 동작하는가 → `champion 사진/이름 표시, 다시하기로 16강 처음부터 재시작(코드상 구현됨, 사진 결함은 동일하게 전이됨)`
