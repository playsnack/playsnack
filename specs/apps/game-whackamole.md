# 두더지 잡기 `game-whackamole`  ·  game

**Verdict:** needs-fix  ·  **Mode:** single

## 주제 매력도
'두더지 잡기(whack-a-mole)'는 오락실/모바일 캐주얼의 국민 포맷이라 누구나 룰 설명 없이 즉시 이해한다. '15초 안에 몇 번?' 형태의 반응속도 챌린지는 점수 자랑·재도전 욕구가 강해 휘발성 스낵에 완벽히 맞는다. 다만 현재 캐릭터가 두더지가 아니라 햄스터(🐹) 이모지라 주제-비주얼이 어긋난다. 두더지 느낌의 이모지(예: 흙더미에서 튀어나오는 연출 + 갈색 동물)로 바꾸거나, 차라리 콘셉트를 햄스터에 맞춰 '햄스터 잡기'로 정직하게 통일하면 더 매력적이다.

## 레퍼런스 (검증된 인기 포맷 모방)
- **모방 대상:** 두더지 잡기 (Whac-A-Mole) — 오락실/모바일 캐주얼 반응속도 게임의 표준 포맷
- **구조 100% 복제:** 검증된 룰을 100% 모방: (1) 격자 형태의 구멍들, (2) 무작위 한 구멍에서 두더지가 튀어나옴, (3) 제한시간(15초) 카운트다운, (4) 두더지를 탭하면 +1점 후 즉시 다른 구멍으로 이동, (5) 시간 종료 시 최종 점수 + 평가 메시지 + 다시하기. 시작→플레이→결과 3-state 흐름과 점수/타이머 HUD 구조 그대로 차용.
- **우리 콘텐츠/디자인:** 콘텐츠: 한국어 카피('보이면 바로 탭!', 점수대별 평가 멘트), 캐릭터(현재 햄스터 이모지→두더지로 교정 필요). 디자인: 블랙(#0b0c0e/#111317) 배경 + 라임(#d9ff00) 두더지/버튼 톤, StatCard 기반 점수·타이머 HUD.

## 목적
심심한 1분, '나 반응속도 좀 빠른가?'를 확인하고 싶을 때 여는 즉석 스낵. 15초 동안 튀어나오는 두더지를 정신없이 탭해 점수를 쌓고, 결과 점수로 자기 손 빠르기를 가늠하며 '한 판 더'를 부르는 짧고 강한 손맛이 재미다.

## 핵심 루프
제한시간 15초 동안 무작위 구멍에 나타나는 두더지를 탭 → 탭마다 +1점 & 두더지는 즉시 다른 구멍으로 이동 → 시간이 끝나면 최종 점수와 평가가 표시되고 다시하기로 반복.

## 시나리오
1. 사용자가 앱을 열면 시작 화면: 제목 '두더지 잡기', 두더지 캐릭터, 룰 설명, 라임 '시작' 버튼이 보인다
2. '시작'을 탭하면 → score=0, startedAt=현재시각, moleIndex=랜덤으로 초기화되고 play 상태로 전환
3. 플레이 화면: 상단에 '점수 0점'/'남은 시간 15초' HUD, 아래 격자형 플레이 필드에 6개 구멍 중 한 곳에서 두더지가 나타난다
4. 사용자가 두더지를 탭하면 → 점수 +1, 두더지가 즉시 다른 구멍으로 이동(연출), 탭마다 손맛 있는 즉시 피드백
5. 남은 시간 카드가 매 프레임 1초씩 줄어든다(15→0)
6. 타이머가 0이 되면(경과 >= duration) → 자동으로 결과 화면으로 전환
7. 결과 화면: 🎉, '기록 달성!', 최종 점수, 점수대별 평가 멘트(20+/12+/그 외)가 표시된다
8. '다시하기'를 탭하면 → 시작 화면(ready)으로 돌아가 새 게임 준비

## 성공 기준
- 플레이 화면에서 6개 구멍이 격자(3×2)로 또렷하게 보여 '두더지 잡기' 보드임을 한눈에 알 수 있다
- 두더지가 항상 6개 구멍 중 하나에 정확히 겹쳐서 나타난다(허공이 아니라 구멍 위)
- 탭할 때마다 점수가 즉시 +1 변하고, 두더지가 눈에 띄게 다른 구멍으로 점프한다(데드타임 0)
- 남은 시간 숫자가 15→0으로 실시간 감소하는 게 보인다
- 텍스트가 겹치거나 화면 밖으로 잘리지 않고, 빈 검은 영역 없이 플레이 필드가 보드처럼 채워진다
- 결과 화면에 실제 획득 점수와 점수대에 맞는 평가 멘트가 정확히 표시된다
- 캐릭터 이모지가 제목('두더지')과 일치한다

## 현재 깨짐 (진단)
- **[high]** 플레이 화면에서 6개 구멍이 보이지 않는다 — 플레이 필드가 거대한 빈 검은 박스로 렌더된다. 게임의 핵심인 '두더지 잡기 보드'가 사라진 상태.
  - 근거: shots 2·3에서 playArea(height 430)가 거의 전면 검정. 구멍 색 hole 색상 #1b2030이 필드 #111317과 사실상 구분 안 됨. 시작 화면이 약속한 '3×2 구멍'이 화면에 없음. 구조상 hole0~5는 playArea(line 242)의 자식인데 playArea에 layout이 없어 절대좌표로 배치되지만, 시각적으로 거의 안 보임.
  - 수정: 구멍을 배경과 또렷이 대비되는 색/테두리로(예: 더 밝은 surface + 라임 림 또는 진한 안쪽 그림자) 항상 보이게. playArea에 명시적 grid/flex 레이아웃(3열×2행, gap)을 주거나 구멍 좌표·크기를 필드 크기에 맞춰 재배치해 6개가 격자로 꽉 차게.
- **[high]** 두더지가 구멍 위에 겹치지 않고 허공에 뜬다 — 좌표 불일치.
  - 근거: 바인딩 mole.x=[35,143,251,35,143,251](line 675), mole.y=[22,22,22,194,194,194](line 676). 그러나 hole 좌표는 x:28/136/244(line 268,297,327…), y:72/244(line 268,357…). x는 약 7px, y는 약 50px 어긋남. shot2의 두더지(우상단)·shot3(좌하단)이 어떤 구멍에도 안 얹혀 검은 공간에 떠 있음.
  - 수정: mole의 x/y 배열을 hole 컨테이너의 실제 좌표와 정확히 일치(두더지 폭/높이 차이를 보정한 중앙정렬 오프셋)로 다시 계산. 가능하면 구멍과 두더지를 같은 그리드 셀 좌표계로 통일.
- **[medium]** 플레이 필드 좌하단에 정체불명의 둥근 사각형 도형들이 필드 밖으로 새어나와 'quitHint' 텍스트 영역과 겹친다.
  - 근거: shots 2·3 모두 playArea 카드 아래·왼쪽 가장자리에 흐릿한 rounded-rect 도형 무리가 보이고 '끝나면 자동으로 결과가 표시돼요' 텍스트 좌측과 시각적으로 겹침. 구멍 컨테이너가 필드 클리핑 밖으로 비져나와 렌더되는 것으로 보임(clip 미적용 또는 좌표가 카드 경계를 벗어남).

- **[low]** 캐릭터가 두더지가 아니라 햄스터(🐹) 이모지 — 제목·콘텐츠와 불일치.
