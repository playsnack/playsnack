# 너는 무슨 동물? `test-animal`  ·  psych

**Verdict:** needs-fix  ·  **Mode:** single

## 주제 매력도
"나는 무슨 동물?" 캐릭터 심리테스트는 한국 SNS/카톡 공유에서 검증된 초강력 바이럴 주제다(MBTI 동물화, ㅇㅇ 동물상 테스트 등). 4종 동물(고양이/강아지/토끼/여우) 결과는 공유·캡처 욕구가 크고, 결과를 친구와 비교하는 재미가 확실하다. 주제 자체는 매우 매력적이라 바꿀 필요 없음. 다만 결과가 단 4종이라 변별력이 얕아 보일 수 있으니, 동물별 한줄 별명("고요한 달빛 고양이")과 짧은 성격 카피로 '내 얘기 같다'는 적중감을 끌어올리는 게 핵심.

## 레퍼런스 (검증된 인기 포맷 모방)
- **모방 대상:** 퍼스널 동물상/동물 캐릭터 테스트 (16Personalities·아카네코식 단일선택 심리테스트 포맷)
- **구조 100% 복제:** 검증된 단일선택 심리테스트 룰을 100% 모방: (1) 진행바/카운터가 있는 N문항(여기선 5문항), (2) 한 문항당 4지선다 단일 탭, (3) 각 선택지가 숨은 4개 축(동물)에 +1 가점, (4) 마지막에 최고점 축으로 결과 캐릭터 1개 확정, (5) 결과 화면 = 큰 이모지/일러스트 + 별명 + 성격 카피 + 다시하기. 탭 즉시 다음 문항으로 넘어가는 무(無)데드타임 진행도 그대로.
- **우리 콘텐츠/디자인:** 콘텐츠는 우리 것: 주말 계획/위로 방식/일 추진/방 오브제/마법 능력 5개 한국형 라이프스타일 문항과 동물별 별명·카피를 새로 작성. 디자인은 우리 톤(블랙 #0b0c0e + 라임 #d9ff00): 결과 아우라 그라데이션·다시하기 버튼만 라임으로 포인트, 나머지는 다크 서피스.

## 목적
심심할 때 30초 안에 "나는 무슨 동물 캐릭터인가"를 뽑아보고, 별명+성격 카피로 '내 얘기 같다'는 적중감과 캡처·공유 재미를 얻는 휘발성 스낵 심리테스트. 친구에게 링크 던지고 결과 비교하는 가벼운 놀이.

## 핵심 루프
5개 문항에서 4지선다 중 하나를 탭하면 즉시 다음 문항으로 넘어가고, 5번째 선택 직후 누적 점수 최고 동물이 결과로 확정된다.

## 시나리오
1. 앱을 열면 1/5 문항(상상 속 주말)과 4개 선택지가 보인다
2. 끌리는 선택지 하나를 탭한다 → 해당 동물 변수 +1, 즉시 2/5 문항으로 전환(서브타이틀 카운터가 '2/5 · 관계 스타일'로 바뀜)
3. 같은 방식으로 3/5(에너지 방향), 4/5(취향의 결), 5/5(마법 능력)를 차례로 탭한다
4. 5번째 탭 직후 result 상태로 이동 → 누적 점수 최고 동물로 이모지/별명/성격 카피가 동시에 바인딩되어 표시된다
5. 결과 카드에서 큰 동물 이모지, 별명(예: 고요한 달빛 고양이), 성격 한 문단을 읽는다
6. '다시하기' 버튼을 탭하면 cat/dog/rabbit/fox 점수가 0으로 초기화되고 1/5 문항으로 되돌아간다
7. (공유) 결과 화면을 캡처해 친구에게 보낸다

## 성공 기준
- 문항 카운터(1/5~5/5)와 서브타이틀이 매 선택마다 정확히 바뀌어 진행감이 보인다
- 선택지가 '탭 가능한 카드'로 명확히 보인다 — 카드 표면(테두리/면)이 배경과 구분되어야 함
- 탭 즉시(데드타임 0) 다음 문항으로 전환된다
- 결과 동물이 5개 선택의 누적 점수와 논리적으로 일치한다(예: 혼자/조용 계열을 골랐으면 고양이)
- 결과의 이모지·별명·성격 카피 세 가지가 같은 동물로 일관된다
- 모든 텍스트가 화면 안에 들어오고 줄바꿈/겹침이 없다
- 다시하기 시 점수가 초기화되어 같은 선택이 같은 결과를 재현한다

## QA 검증 시나리오
- [ ] **QA1** 5개 문항 각각의 4개 OptionCard 인스턴스(qNCat/Dog/Rabbit/Fox)가 click 트리거에 응답해 다음 상태로 이동하는가 → `20개 선택지 모두 탭 시 해당 동물 변수 +1 후 정확히 다음 q 또는 result로 전환`
- [ ] **QA2** 서브타이틀 진행 카운터가 상태마다 변하는가 (스크린샷 1/2/3에서 1/5·2/5·3/5 확인됨) → `q1~q5에서 '1/5'~'5/5'로 순차 표시`
- [ ] **QA3** 선택지 카드가 시각적으로 카드로 식별되는가 → `각 OptionCard가 배경과 구분되는 표면(채움 또는 또렷한 테두리)을 가져 탭 영역이 명확 — 현재 실패`
- [ ] **QA4** 결과 분기 식이 점수와 일치하는가 (result 바인딩 tie-break: cat≥dog≥rabbit≥fox 순) → `최고점 동물의 이모지/별명/카피가 일관되게 출력. 동점 시 cat>dog>rabbit>fox 우선순위로 결정`
- [ ] **QA5** 결과 화면 텍스트(별명 29pt, 카피 16pt)가 카드 안에 줄바꿈 깨짐/넘침 없이 들어오는가 → `resultCard(height:hug, padding 22) 안에 이모지+제목+설명+버튼이 정상 배치`
- [ ] **QA6** 다시하기 버튼이 4개 변수를 0으로 리셋하고 q1로 가는가 → `restartBtn 탭 시 cat/dog/rabbit/fox=0, initialState q1 복귀`
- [ ] **QA7** (psych 특유) 결과가 4종 동물을 모두 도달 가능하게 커버하는가 → `각 동물에 가점하는 선택지가 전 문항에 균등 배치(Cat/Dog/Rabbit/Fox 각 5표 가능) — 구조상 충족`

## 현재 깨짐 (진단)
- **[high]** 선택지 OptionCard가 '카드'로 안 보이고 검은 배경 위 떠 있는 맨 텍스트처럼 렌더된다. OptionCard root 색 #16181c(componentDef line 1497)가 부모 hero 컨테이너 색 #16181c(line 81 등)와 완전히 동일하고, 테두리 #2a2d33(line 1498)는 다크 배경에서 거의 보이지 않아 탭 가능한 카드임이 식별되지 않는다.
  - 근거: test-animal-1/2/3.png 모든 화면에서 4개 선택지가 박스 없이 흰 글자만 검은 화면에 떠 있음 — 카드 면/테두리가 전혀 안 보임
  - 수정: OptionCard 표면을 부모와 구분: 채움을 #1e2127(혹은 더 밝게)로 올리거나 stroke를 #3a3f47/1.5px로 강화. 탭 가능성을 위해 라임 좌측 악센트 바 또는 약한 그림자 추가.
- **[medium]** 선택지 사이 세로 여백이 과도하게 벌어져 화면이 비어 보인다. 옵션 컨테이너가 height:'fill'(line 124/269 등)에 gap:10인데, 고정 88px 카드 4개가 남는 fill 공간 때문에 멀리 떨어져 배치되어 큰 검은 빈 영역이 생긴다. 카드 면이 안 보이는 결함과 겹쳐 '랜덤하게 흩어진 텍스트'로 읽힌다.
  - 근거: test-animal-1/3.png: 4번째 선택지 아래/사이로 큰 검은 공백. 옵션들이 화면 하단까지 띄엄띄엄 흩어짐 — 밀도가 낮아 snack답지 않음
  - 수정: 옵션 컨테이너를 height:'hug'+gap 12~14로 바꿔 카드를 위쪽에 모으거나, 카드 height를 줄여(64~72) 간격을 일정하게. fill로 벌릴 거면 justifyContent:'space-between' 대신 카드 표면을 살려 의도된 리듬으로.
- **[low]** OptionCard에 선택/탭 피드백이 없다(accent는 항상 false). 휘발성 스낵의 'snappy 즉시 피드백' 원칙상 탭 순간 라임 플래시/하이라이트가 없으면 입력이 먹혔는지 불확실(다만 즉시 다음 문항 전환이 피드백 역할은 함).
  - 근거: componentDef OptionCard accent default false(line 1487), 모든 인스턴스 accent:false. 탭 시 상태 변화 외 시각 피드백 없음
  - 수정: 탭 시 잠깐 라임 테두리/배경 플래시 또는 최소한 카드 표면을 또렷이 해 press 영역을 명확히.
