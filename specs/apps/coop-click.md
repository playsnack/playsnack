# 다같이 1만번 클릭 `coop-click`  ·  counter

**Verdict:** needs-fix  ·  **Mode:** multi (co-op tally (서버 합산 공동 게이지) — emitHostEvent 'tally' delta=1 → 서버가 coopTotal을 setVar로 전체 동기화)

## 주제 매력도
"다같이 1만번 클릭"은 라이브 군중이 하나의 게이지를 함께 채우는 집단 목표 챌린지로, 트위치의 'Twitch Plays' 류와 유튜브 라이브 카운트다운처럼 '내 탭 하나가 전체에 보태진다'는 군중 소속감이 강하게 먹히는 검증된 포맷이다. 한국에서도 응원 클릭/실시간 동접 카운트 류는 인기다. 다만 목표 10,000은 군중이 없으면 절대 안 차므로 체감 진척이 0에 머문다 — 주제 자체는 매력적이나 '눈에 보이는 진척'을 위해 목표를 동적(예: 인원수×N, 또는 1000 단위 마일스톤 연출)으로 조정하면 훨씬 더 끌린다.

## 레퍼런스 (검증된 인기 포맷 모방)
- **모방 대상:** Twitch Plays / 유튜브 라이브 동접 카운터 + Cookie Clicker 식 누적 탭
- **구조 100% 복제:** 단일 공동 게이지를 향해 모든 참가자의 탭이 서버에서 실시간 합산되어 한 숫자/진척바로 표시되는 집단 누적 루프. 개인 기여(내 탭)와 전체 합계를 나란히 보여주고, 마일스톤 도달 시 축하 연출로 보상하는 흐름.
- **우리 콘텐츠/디자인:** 콘텐츠=한국어 카피('탭해서 힘 보태기', 'LIVE CO-OP', 1만 목표)와 마일스톤 문구를 우리가 채움. 디자인=블랙(#0b0c0e)+라임(#d9ff00) 톤, iOS componentDef(NavBar/StatCard/Button/Chip) 기반 카드 레이아웃.

## 목적
여럿이 동시에 접속해 하나의 공동 목표(1만 탭)를 향해 화면을 마구 탭하는 라이브 협동 챌린지. 소비자는 '내 탭이 모두의 게이지에 즉시 보태진다'는 군중 소속감과, 숫자가 실시간으로 함께 차오르는 즉각적 쾌감을 30초~몇 분 안에 휘발적으로 소비한다.

## 핵심 루프
큰 라임 버튼(또는 탭존)을 누른다 → 서버가 모두의 탭을 합산해 공동 카운터와 진척바가 실시간으로 차오른다.

## 시나리오
1. 링크로 입장하면 상단에 '공동 클릭 챌린지' 타이틀, 중앙 히어로 카드에 'LIVE CO-OP / 0 / 10,000 / 0% 완료', 우상단에 동접 인원(예: 1)이 보인다
2. 사용자가 하단 '+1 공동 탭' 버튼 또는 탭존을 누른다 → 로컬 myTaps+1, 서버로 tally 이벤트(delta=1) 전송
3. 서버가 모든 참가자의 delta를 합산해 coopTotal을 갱신, setVar로 전체 클라이언트에 브로드캐스트
4. 히어로의 큰 숫자가 0→1→2…로 즉시 올라가고 진척바·퍼센트가 함께 차오른다 (스크린샷 1→2→3에서 0→1→2 확인됨)
5. '전체 탭'은 공동 합계, '내 탭'은 내 기여분을 실시간 반영해야 한다
6. 여럿이 동시에 연타하면 숫자가 가속해 차오르며 군중감이 형성된다
7. 마일스톤/목표 도달 시 축하 연출로 보상 (현재 미구현)
8. 사용자는 흥미가 식으면 그냥 떠난다 — 별도 결과/리셋 없이 휘발적으로 종료

## 성공 기준
- 탭 즉시 히어로 카운터가 데드타임 없이 올라간다(즉시성)
- 공동 합계와 내 기여가 둘 다 정확히 보이고 실시간으로 변한다
- 진척바와 퍼센트가 카운트에 비례해 시각적으로 차오른다
- 텍스트가 겹치거나 줄바꿈으로 깨지지 않고 화면 안에 들어온다
- 여럿이 함께 탭할 때 합산이 빠르고 자연스럽게 반영되어 '같이 하는' 군중감이 살아난다
- 목표 도달이 시야에 들어오는 진척감(데모 중에도 바가 눈에 띄게 움직임)

## 현재 깨짐 (진단)
- **[high]** StatCard 두 개('전체 탭', '내 탭')의 값이 0에 고정 — 히어로 카운터가 1·2로 올라가도 카드는 전부 '0'
  - 근거: 스크린샷 1·2·3: 히어로는 0→1→2인데 '전체 탭 0', '내 탭 0' 불변. 문서 line 281-282에 sharedStat.value/myStat.value 바인딩이 있으나, 직접 text 레이어인 totalText(line 277)는 갱신되는 반면 component 인스턴스의 prop 바인딩은 내부 val 텍스트로 전파되지 않음. '내 탭'은 탭마다 myTaps+1(line 292)이므로 최소 내 기기에선 0이 아니어야 함
  - 수정: StatCard 인스턴스 prop 바인딩 전파를 고치거나, StatCard 대신 직접 text 레이어(totalText처럼)로 '전체 탭'/'내 탭' 숫자를 만들어 sharedStat val.content/myStat val.content를 직접 바인딩. 또는 propValues에 expr 바인딩을 거는 경로가 런타임에서 동작하도록 수정
- **[medium]** 진척바가 데모 내내 시각적으로 0 — 목표 10,000이 비현실적으로 커서 진척감이 없음
  - 근거: count 2에서 barFill width=round(2/10000*322)=0px. 단일 데모/소규모에선 바가 절대 안 움직여 '아무 일도 안 일어남'으로 보임
  - 수정: goal을 동적(접속 인원 기반 또는 1000 단위 마일스톤 연출 추가)으로 조정하거나, 최소 1px 보장 + 마일스톤 도달 펄스 연출로 작은 진척도 체감되게 함
- **[low]** '0% 완료' 텍스트가 두 줄로 줄바꿈됨
  - 근거: 스크린샷 전부 '0%'와 '완료'가 줄바꿈되어 2줄. percentText에 폭 지정이 없고 중앙정렬 flex column 안에서 한국어가 래핑됨
  - 수정: percentText에 충분한 width(예: 'fill' 또는 명시 폭) 지정 또는 whiteSpace nowrap 처리로 한 줄 유지
- **[low]** 목표 도달 보상/완료 상태 부재
  - 근거: 문서 states에 idle 단일 상태만 존재(line 274-327). goal=10000 도달 시 축하/완료 연출이나 상태 전환 없음 — 협동 챌린지의 클라이맥스 보상이 빠짐
  - 수정: coopTotal>=goal 조건의 완료 상태/연출(콘페티·전원 메시지) 추가로 군중의 달성 모먼트 보상
