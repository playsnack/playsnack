# 반응속도 테스트 `game-reaction`  ·  game

**Verdict:** needs-fix  ·  **Mode:** single

## 주제 매력도
반응속도 테스트는 전 세계적으로 검증된 초대형 캐주얼 포맷이다(humanbenchmark.com Reaction Time이 대표). "빨강일 때 기다렸다가 초록으로 바뀌는 순간 탭"은 누구나 룰 설명 0초로 이해하고, ms 단위 기록 경쟁이 즉시 자존심을 건드린다. 한국에서도 "내 반응속도 몇 ms?" 자랑/내기 콘텐츠로 잘 통하는 주제다. 휘발성 스낵에 최적: 한 판 2~5초, 무한 반복, 친구에게 "너 몇 나옴?" 던지기 좋음. 주제 자체는 강력하므로 바꿀 필요 없고, 결과 문구를 한국식 등급(예: "치타급 200ms↓", "보통 사람 250~300ms", "방금 일어났니? 400ms↑")으로 채우면 공유 매력이 더 커진다.

## 레퍼런스 (검증된 인기 포맷 모방)
- **모방 대상:** Human Benchmark — Reaction Time Test
- **구조 100% 복제:** 검증된 reflex-test 표준 룰/흐름을 100% 모방: (1) 대기 화면에서 시작 → (2) 무작위 지연(1.2~4초) 동안 '빨강/기다려' 표시 → (3) 초록으로 전환되는 순간부터 ms 측정 시작 → (4) 사용자가 탭하면 경과 ms 기록 → (5) 초록 전 탭하면 '너무 빨랐어요' 실패(평균 미포함) → (6) 결과에 이번 기록·평균·최고 표시, 즉시 재시도. 무작위 지연으로 예측 불가, 페널티로 부정 탭 방지하는 이 구조가 핵심.
- **우리 콘텐츠/디자인:** 콘텐츠: 결과 ms에 따른 한국어 등급/멘트(치타급/평균/느림 등), 격려 카피를 우리가 작성. 디자인: 블랙(#0b0c0e) 배경 + 라임(#d9ff00) 액센트 톤. 단 reflex-test의 생명인 빨강↔초록 색대비는 반드시 살려야 하므로, 빨강 대기=실제 적색, 초록=라임을 '탭하라'는 신호로 사용(라임을 green 역할로). componentDef NavBar/StatCard/Button는 우리 iOS 컴포넌트 라이브러리 재사용.

## 목적
"내 반응속도 몇 ms?"라는 즉각적 호기심과 자존심을 2~5초 만에 충족시키는 휘발성 스낵. 빨강에서 참았다가 초록으로 바뀌는 찰나에 탭해 ms 기록을 받고, 평균·최고를 갱신하며 무한 재도전한다. 룰 설명이 필요 없고 한 손으로 즉시 즐긴다.

## 핵심 루프
시작 → 빨강에서 대기 → 초록으로 바뀌는 순간 탭 → 반응 ms 기록(빨리 누르면 실패) → 다시 시도.

## 시나리오
1. 사용자가 앱을 연다 → ready 화면: 제목 '반응속도 테스트', 오브, 평균/최고(--ms), '시작' 버튼 표시
2. '시작' 탭 → 무작위 지연(1.2~4초)을 설정하고 waiting 상태로 전환, '빨강' 대기 화면 표시
3. 대기 중 사용자가 참는다 → onFrame이 매 프레임 경과시간 체크, 지연 도달 시 greenAt 기록 후 green 상태로 전환('지금! 탭하세요')
4. 초록 화면에서 사용자가 탭 → 경과 ms = now - greenAt 계산, lastMs/totalMs/bestMs/attempts 갱신, result 상태로 전환
5. result 화면: 이번 ms를 큰 숫자로, 평균·최고 갱신 표시, '다시 시도' 버튼
6. '다시 시도' 탭 → 다시 무작위 지연 설정 후 waiting으로 → 루프 반복
7. (이탈 경로) 대기 중 초록 전에 탭 → fail 상태: '너무 빨랐어요', 이번 시도는 평균 미포함, '다시 준비'로 재시작

## 성공 기준
- 빨강(대기) 영역이 실제 붉은색으로, 초록(탭) 영역이 라임/녹색으로 렌더되어 색만 보고도 '기다림/탭'을 구분할 수 있다
- 대기→초록 전환이 즉각적이고, 초록 탭 즉시 ms 결과가 데드타임 없이 나타난다(snappy)
- 평균/최고/이번기록 숫자가 실제 측정값으로 갱신되어 보인다(첫 성공 후 -- 가 실제 ms로 바뀜)
- 모든 화면에서 텍스트가 겹치지 않고 화면 안에 들어오며, 컨테이너가 collapse 없이 의도된 영역을 채운다(거대한 빈 검은 영역 없음)
- 결과 ms 등급/멘트가 실제 기록과 일치하고 한국어로 자연스럽다
- 룰(빨강 기다림/초록 탭, 빨리 누르면 실패) 학습이 별도 설명 없이 화면만으로 즉시 된다

## 멀티 변형 아이디어 (별도 앱)
멀티로 매우 잘 어울림. live-race 메커닉: 같은 방의 N명이 동시에 동일한 빨강→초록 신호를 받고(서버가 greenAt를 setVar로 전 클라 동기화 — 레거시 엔진 실시간 훅에 정확히 맞음), 가장 먼저 정확히 탭한 사람이 그 라운드 승. 부정 출발(초록 전 탭)은 그 라운드 탈락. 라운드 누적 점수로 베스트오브-N. 기존 검증된 vote 블록과 달리 '동시 신호 + 최초 정답 탭'이라 별도 멀티 컨트랙트가 필요하므로 지금 이 single 앱과 분리된 'game-reaction-versus' 앱으로 만드는 것을 권장.
