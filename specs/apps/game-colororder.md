# 색깔 순서 기억 `game-colororder`  ·  game

**Verdict:** needs-fix  ·  **Mode:** single

## 주제 매력도
색 순서 기억(메모리 시퀀스)은 'Simon Says'/'순서 기억 게임' 계열로, 한국에서도 뇌훈련·집중력 테스트로 꾸준히 소비되는 검증된 포맷이다. 규칙 설명이 거의 필요 없고(보고→따라 탭) 즉시 빠져드는 점이 스낵앱에 딱 맞다. 다만 현재 콘텐츠가 '추상적 색 4개'라 정서적 후킹은 약하다. 더 매력적으로 가려면 색 자체를 KR 친화 테마(예: '신호등 순서', '아이돌 응원봉 색 순서', '편의점 음료 컬러 순서')로 래핑하거나, 결과를 '금붕어 기억력 / 코끼리 기억력' 같은 등급 밈으로 주면 공유 욕구가 커진다.

## 레퍼런스 (검증된 인기 포맷 모방)
- **모방 대상:** Simon (사이먼 게임) / 순서 기억 두뇌게임
- **구조 100% 복제:** 검증된 메모리-시퀀스 룰을 100% 모방: (1) 시스템이 색 시퀀스를 순서대로 잠깐 제시 → (2) 가린 뒤 → (3) 유저가 본 순서대로 탭 → (4) 전부 맞히면 시퀀스를 1개 늘려 다음 라운드, 한 번이라도 틀리면 즉시 게임오버 → (5) '몇 단계까지 도달'을 점수로. 라운드마다 길이가 늘어 난이도가 점증하는 무한 진행 구조.
- **우리 콘텐츠/디자인:** 룰은 동일하되 콘텐츠/비주얼은 우리 것: 블랙(#0b0c0e)+라임(#d9ff00) 톤, 4색 카드(red/blue/yellow/green), 한국어 카피('순서를 보고, 그대로 탭하세요'), 결과 등급을 KR 밈 카피로. 현재는 색 4종이 추상적이라 테마(신호등/응원봉/음료 등)로 콘텐츠 슬롯을 채우면 모범 템플릿이 된다.

## 목적
짧은 틈에 '내 순간 기억력이 얼마나 되나' 확인하는 휘발성 두뇌 스낵. 색 카드가 잠깐 떴다 사라지면 그 순서를 그대로 탭해 단계를 올리고, 어디까지 갔는지로 자기 기록을 가볍게 즐긴다. 한 판이 수초~수십초로 끝나 데드타임 없이 즉석 소비된다.

## 핵심 루프
색 순서를 잠깐 보고(show) → 가려지면 본 순서대로 색을 탭(input) → 전부 맞으면 한 단계 길어진 다음 라운드, 틀리면 결과 화면으로.

## 시나리오
1. 유저가 앱을 연다 → ready 화면: 타이틀 '색의 리듬을 기억해 보세요' + 설명 + '시작하기' 버튼 노출
2. '시작하기' 탭 → level=1, inputIndex=0, startedAt=$now 세팅 후 show 상태로 전환
3. show 화면: 단계/기억할 카드(3장) 스탯과 색 카드 그리드(1·2·3번 색)가 노출, 'N초 뒤 가려져요' 카운트다운 표시
4. showDuration(2.2초) 경과 → onFrame 트리거가 자동으로 input 상태로 전환
5. input 화면: 카드는 '가려졌습니다' 안내 + RED/BLUE/YELLOW/GREEN 4색 탭 버튼 그리드 노출
6. 유저가 본 순서대로 색을 탭 → 맞으면 inputIndex 증가, 진행 스탯이 '1/3 → 2/3' 갱신
7. 마지막까지 맞히면 level+1, 다시 show로(시퀀스 1장 더 길게) — 무한 진행
8. 한 번이라도 틀리면 즉시 result 화면: '🧠 기억 완료! / N단계 도달' + '다시 도전' 버튼
9. '다시 도전' 탭 → level/inputIndex 리셋 후 ready로 복귀

## 성공 기준
- show→input→show 루프가 데드타임 없이 매끄럽게 돌고, 카운트다운/단계/진행 숫자가 실제로 보이며 변한다
- show 화면에서 색 카드와 안내/힌트 텍스트가 서로 겹치지 않고 각자 자리에 깔끔히 배치된다
- 4색 탭 버튼이 모두 실제 반응하고, 정답/오답 판정이 시퀀스와 정확히 일치한다
- ready 히어로 비주얼이 의도한 라임 그라데이션으로 보이고(현재 회색 깨짐), 블랙+라임 톤이 일관된다
- 결과 화면의 '도달 단계' 숫자가 실제 플레이한 도달 단계와 정직하게 일치한다
- 난이도가 라운드마다 한 장씩 정확히 늘어 점증하는 것이 체감된다

## 멀티 변형 아이디어 (별도 앱)
멀티 버전이 매우 재밌을 수 있음: '같이 패스-앤-플레이 시퀀스 빌더' — 플레이어 A가 기존 시퀀스를 따라 친 뒤 색 1개를 추가, 플레이어 B는 늘어난 전체를 재현하고 또 1개 추가하는 turn 방식(클래식 Simon 멀티 룰). 또는 같은 시퀀스를 동시에 풀어 더 오래 버틴 사람이 이기는 live-race 관전 모드. 둘 다 turn/live-race 메커닉이라 현 vote 컨트랙트와 별개의 신규 멀티 컨트랙트 필요.
