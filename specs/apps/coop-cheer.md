# 응원 떼창 게이지 `coop-cheer`  ·  reaction

**Verdict:** broken  ·  **Mode:** multi (co-op tally — 여러 참여자의 탭 delta를 서버가 한 공동 카운터(coopTotal)에 합산하고 setVar로 전체 동기화하는 라이브 협동 집계)

## 주제 매력도
단체 응원 떼창은 콘서트·스포츠·팬덤 문화에서 검증된 강력한 "함께 채운다"는 집단 카타르시스를 준다 — 한국은 떼창/응원법/총공(스밍) 문화가 세계 최강이라 주제 친화도가 매우 높다. 다만 추상적인 "응원 에너지"보다는 구체적 대상(좋아하는 아이돌 무대, 우리 팀 골 세리머니, 친구 생일 축하 떼창 등)을 슬롯으로 채워야 더 끌린다. 주제는 유지하되 "무엇을 향한 응원인가"를 명시하면 매력이 커진다.

## 레퍼런스 (검증된 인기 포맷 모방)
- **모방 대상:** Twitch "Power Up"/Hype Train + 콘서트 응원봉 떼창 (집단 progress-bar 채우기 포맷)
- **구조 100% 복제:** 여러 명이 동시에 한 공동 게이지에 입력을 합산해 공동 목표를 향해 차오르고, 임계치 달성 시 단체 보상/축하 연출이 터지는 라이브 집단 메커닉 — 룰/진행 흐름(공동 카운터 + 실시간 합산 + 목표 게이지 + 달성 셀러브레이션)을 100% 모방.
- **우리 콘텐츠/디자인:** 콘텐츠: 응원 대상/목표 문구/달성 시 축하 카피를 KR 팬덤·스포츠 톤으로 새로 작성하고, 목표치를 스낵 규모(예: 30초 안에 다같이 채울 수 있는 100~300탭)로 재설정. 디자인: 블랙(#0b0c0e)+라임(#d9ff00) 톤, 라이브 게이지 펄스/탭 햅틱 피드백은 우리 비주얼로.

## 목적
콘서트/경기/팬 모임에서 여러 사람이 같은 화면 링크를 열고 동시에 탭해 하나의 응원 게이지를 함께 채우는 라이브 집단 스낵. "나 혼자가 아니라 다같이 만들었다"는 즉석 떼창의 집단 쾌감을 30초 안에 휘발적으로 소비한다.

## 핵심 루프
'응원 탭 보내기'를 연타 → 내 탭이 공동 게이지에 실시간 합산돼 모두의 화면에서 게이지가 같이 차오르고, 목표 도달 시 단체 축하 연출이 터진다.

## 시나리오
1. 호스트가 링크 공유 → 여러 명이 같은 세션 입장(우상단 인원수 카운터에 인원 표시)
2. 사용자가 화면을 보면 공동 게이지·공동 합계·내 응원·목표(%)가 0에서 대기
3. 사용자가 '응원 탭 보내기'를 탭 → 내 응원 +1, emitHostEvent('tally',{delta:1})로 서버에 전송
4. 서버가 모든 참여자의 delta를 합산해 coopTotal을 setVar로 전체 동기화 → 모두의 게이지/공동 합계/퍼센트가 동시에 차오름
5. 여러 명이 동시 연타 → 게이지가 빠르게 차오르며 라이브 집단감 발생
6. coopTotal이 goal에 도달 → 셀러브레이션 카드가 '🎉 목표 달성!' + 라임 컬러 축하 메시지로 전환
7. 달성의 집단 카타르시스를 맛본 뒤 화면을 닫거나 새 응원 세션으로 반복

## 성공 기준
- 탭 한 번에 내 응원·공동 합계·게이지·퍼센트가 즉시(데드타임 0) 갱신돼 보인다
- 공동 합계와 내 응원 숫자가 실제로 화면에서 변한다(고정 0이 아님)
- 게이지 fill 바가 진척에 따라 눈에 보이게 차오른다
- 목표치가 다같이 30초~1분 내 채울 수 있는 스낵 규모여서 달성 카타르시스를 실제로 경험한다
- 달성 시 셀러브레이션 카드가 명확히 축하 상태로 전환된다
- 모든 텍스트가 겹치지 않고 390x844 화면 안에 들어온다
- 블랙+라임 톤이 일관되고 라이브 집단 응원의 에너지가 비주얼로 전달된다
