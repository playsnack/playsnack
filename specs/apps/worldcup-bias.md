# 최애 월드컵 `worldcup-bias`  ·  worldcup

**Verdict:** needs-fix  ·  **Mode:** single

## 주제 매력도
아이돌 "최애 월드컵"은 한국에서 검증된 초강력 주제다. 이상형 월드컵 포맷이 K-pop 팬덤과 만나면 즉석 소비·공유·"내 최애 인증" 동기가 강력하게 작동한다. 다만 현재 데이터소스 theme=아이돌이 너무 광범위해 다른 그룹 멤버가 섞여 비교가 어색할 수 있다. 더 매력적으로 만들려면 그룹별/세대별 테마(예: "걸그룹 최애", "보이그룹 최애", "4세대 아이돌")로 좁혀 같은 결의 후보끼리 붙이는 편이 좋다. 주제 자체는 바꿀 필요 없이 최상급으로 매력적.

## 레퍼런스 (검증된 인기 포맷 모방)
- **모방 대상:** 이상형 월드컵 (PIKU 이상형 월드컵)
- **구조 100% 복제:** 16강 토너먼트 1:1 대결 → 둘 중 하나 탭 → 승자가 다음 라운드 진출 → 8강·4강·결승 → 우승자(나의 최애) 발표 → 다시하기. 라운드 라벨('16강 · N번째 대결'), 상/하 2분할 큰 이미지+이름 오버레이, 중앙 VS — 바이럴 포맷을 100% 모방.
- **우리 콘텐츠/디자인:** 콘텐츠는 한국 아이돌 후보(이름+이미지 쿼리)를 LLM/dataSource로 신선하게 채우고, 디자인은 블랙(#0b0c0e)+라임(#d9ff00) 톤·라운드 카드·라임 VS·라임 우승 배지로 우리 비주얼.

## 목적
사용자가 좋아하는 아이돌 둘 중 한 명을 즉석에서 고르는 가벼운 토너먼트로, 손가락 몇 번만에 "오늘 내 최애"를 가려내는 휘발성 재미. 고민 없이 직관적으로 탭하며 진행하고 마지막 우승자를 캡처/공유하고 싶게 만드는 스낵 게임.

## 핵심 루프
상/하로 마주 선 두 후보 중 한쪽 이미지를 탭하면 승자가 다음 대결로 진출하고, 16강→결승까지 반복해 마지막 한 명을 나의 최애로 발표한다.

## 시나리오
1. 앱 열기 → dataSource(/api/content?kind=worldcup&theme=아이돌)에서 16명 후보를 받아 current 배열에 채우고 '16강 · 1번째 대결'로 play 상태 진입
2. 화면에 상단 optionA·하단 optionB 두 후보의 이미지+이름이 표시되고 중앙에 라임색 VS
3. 사용자가 한쪽 카드를 탭 → 그 후보가 winners에 누적되고 matchIndex+1, 다음 대결 즉시 표시(데드타임 0)
4. 해당 라운드 마지막 대결을 마치면 winners를 current로 승격, roundSize 절반(8강→4강→결승), matchIndex 0으로 초기화하고 라운드 라벨 갱신
5. 결승(roundSize===2)에서 한쪽을 탭 → champion 설정 후 result 상태로 전환
6. result 화면에 '🏆 나의 최애' + 우승자 이미지(260x260) + 이름 + 서브카피 표시
7. 사용자가 '다시하기' 탭 → seed로 current 복원, 모든 변수 초기화 후 play로 재진입

## 성공 기준
- 탭 한 번에 즉시 다음 대결로 넘어가며 로딩 체감/데드타임이 없다
- 두 후보 이미지가 화면을 가득 채우고 이름이 하단에 안 겹치게 오버레이된다
- 라운드 라벨(16강·N번째)이 실제 진행과 정확히 일치한다
- 후보 이미지가 이름과 동일 인물의 실제 얼굴 사진이다(가장 중요 — 최애 월드컵의 본질)
- 후보들이 같은 결(예: 아이돌)이라 비교가 자연스럽다
- 결승 후 우승자 화면이 깔끔히 뜨고 다시하기로 즉시 재시작된다

## QA 검증 시나리오
- [ ] **QA1** optionA/optionB 카드 탭이 실제로 응답해 다음 대결 또는 result로 전환되는가 → `각 탭마다 새 후보쌍 표시, 결승 탭 시 result 전환`
- [ ] **QA2** 라운드 진행 표시(roundLabel)가 보이고 단계마다 변하는가 → `'16강 · 1번째' → 매치마다 번호 증가 → 라운드 끝나면 '8강 · 1번째'로 갱신`
- [ ] **QA3** 후보 이름 텍스트가 이미지 위에서 안 겹치고 카드 안에 들어오는가 → `하단 그림자 영역(y224~300) 내 한 줄로 표시, 잘림/겹침 없음`
- [ ] **QA4** 후보 이미지가 이름과 일치하는 실제 그 인물의 사진인가 → `'장원영'=장원영 본인 얼굴 등 이름=인물 일치`
- [ ] **QA5** 우승자 화면이 챔피언 이미지+이름을 정확히 표시하고 다시하기가 동작하는가 → `마지막 탭한 후보가 챔피언으로 표시, 다시하기 시 16강 재시작`
- [ ] **QA6** 카테고리 특유: 16→8→4→2 토너먼트 수가 맞아 시드 16명이 정확히 소진되는가 → `15번 대결 후 정확히 1명 우승, 부전승/중복 없음`

## 현재 깨짐 (진단)
- **[high]** 이미지가 이름과 전혀 다른 대상 — '장원영' 카드에 길거리 고양이 동상 사진, '카리나' 카드에 빨간 땋은머리의 무관한 여성 사진(screenshot 1). 최애 월드컵의 본질(실제 그 인물 얼굴 비교)이 깨짐
  - 근거: worldcup-bias-1.png: 상단 '장원영' 라벨 아래 보도블록 위 고양이 동상, 하단 '카리나' 라벨 아래 노란 옷 입은 미지의 여성. 문서 bindings topImg.imageUrl = '/api/img?q=' + current[...].q (line 67) — 이미지 검색이 명명 엔티티에 대해 잘못된 결과 반환
  - 수정: named entity는 Wikipedia/위키미디어 인물 사진을 1차 소스로 강제(메모리 'Image relevance: Wikipedia as primary source'와 일치). 후보 q에 그룹명+멤버명+'프로필'을 붙여 검색 정확도 상향, 인물 얼굴 사진만 통과하도록 필터.
- **[high]** 인물 단독 포트레이트가 아니라 그룹 단체/앨범 프로모 이미지가 잡힘 — '제니'에 BLACKPINK 'How You Like That' 텍스트 그래픽, '지수'에 멤버 4명+'FOREVER YOUNG' 단체 포스터(screenshot 2)
  - 근거: worldcup-bias-2.png: '제니' 카드는 앨범 타이틀 텍스트가 큰 프로모 이미지, '지수' 카드는 4인 그룹 포스터. 1:1 대결에서 누가 누군지 식별 불가 — 비교 의미 상실
  - 수정: 이미지 검색을 '단독 인물 포트레이트' 우선으로 랭킹(얼굴 1개 감지/크롭), 그룹샷·텍스트 그래픽·앨범커버 배제. 가능하면 멤버별 위키 인물 이미지 직링크 사용.
- **[medium]** 후보 풀 일관성 부족 가능성 — 장원영(IVE)·카리나(에스파)·제니/지수(BLACKPINK)·사나/나연(TWICE) 등 여러 그룹 멤버가 한 토너먼트에 섞여 있어 'theme=아이돌'이 너무 광범위
  - 근거: 3개 스크린샷에 최소 4개 그룹 멤버 등장. 비교 자체는 가능하나 테마 응집도가 낮아 '최애' 선택 맥락이 흐려짐
  - 수정: dataSource 테마를 더 좁히거나(예: '걸그룹 멤버'), 라운드 라벨/타이틀에 테마를 명시해 사용자가 비교 기준을 인지하도록.
